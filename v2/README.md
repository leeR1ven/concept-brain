# v2：新一代架构的设计与原型（进行中）

最终目标：能实时学习的人工智能架构。当前实例：听别人说话，通过肌肉回答，边对话边学。

## 这一轮做了什么
1. **整体审查**（`docs/review/`）：5 个不同背景的审查（神经科学、学习与记忆、发育心理、AI 理论、怀疑者）
   回答同一组问题——"和真实人脑有哪些区别""整个架构有哪些问题""该优先改什么"。
   共识见 `docs/review/SYNTHESIS.md`。要点：
   - 身体部分（轮流说话、按拍发音、会停）保留；
   - 旧架构里会学习的部分没有接到行为上，没有学出来的表征，老师一走就不学；
   - 学习规则要加：预测误差、学来的抑制、联想区"一起亮就加强"、资格痕迹 + 全脑"奖励/意外"信号；
   - 海马体改成"一次记住、记得久、会回放"；训练改成像孩子学说话的分阶段小世界，不再推嘴。
2. **共享测试台**（`bench/`，`python3 bench/selftest.py`，29 项自检）：有场景的小世界，5 个阶段
   （A 听和咿呀、B 看着物体命名、C 句型带空位、D 关系和记忆、E 成人对话）、三种教法（示范 / 改说 / 推嘴）、
   防作弊基线（重复问句、查表、n-gram、先验、神谕）、与旧 v1 逐拍一致的参考智能体（"基准线"）。
3. **三个独立的完整设计和原型**（都不推嘴：发音靠咿呀学语找到，说什么靠听别人回答学会）：
   - `brainlike/`：照真实大脑分区（背侧复述通路、腹侧理解通路、多层前额叶、基底节闸门、海马体）。
   - `develop/`：照孩子的发育顺序（先听、再咿呀、再模仿和改说；有序句子缓存、组合单元、复制闸门）。
   - `predictive/`：一条统一的局部预测误差规则贯穿全脑（规则单元测试 9/9；学会的轮流说话 Go/NoGo；咿呀记忆让后来听到的新字直接会说）。

## 测试台结果（种子 0，答对率；基准线 = 旧 v1 推嘴训练）
| 任务 | brainlike | develop | predictive | 旧 v1 | 猜最常见答案 |
|---|---|---|---|---|---|
| 指着问"这是什么" | 0.51 | 0.59 | 0.08 | 0.06 | 0.06 |
| "你要X吗→要X" | 0.85 | 0.86 | 0.57 | 0.04 | 0.07–0.09 |
| "这是X吗→是/不是" | 0.48 | 0.77 | 0.21 | 0.46–0.49 | 0.48 |
| 阶段总分 B / C / D | 0.33 / 0.51 / 0.19 | 0.54 / 0.62 / 0.48 | 0.14 / 0.34 / 0.09 | 0.12 / 0.19 / 0.19–0.21 | 0.14 / 0.30 / 0.22 |

机械部分在所有运行中都保持：别人说话时嘴不动、第 6 拍开口、每个字 3 拍。

**还没解决**：学新阶段会冲掉旧本领；没人教时开着学习，回答会被改坏；睡眠回放还没起巩固作用；
一次学会新词、颜色/数量题、"刚才"题；只有一个种子。下一步：分清哪些是"模型小、参数没调好"、哪些要改机制，
然后合成一个统一设计，先小模型短期训练，确实可行再上大模型长期训练。

## 后续实验：问题是"模型太小 / 参数没调好"，还是机制问题？（develop 设计，`develop/followup_report.md`）
| 问题 | 放大模型 | 调参数 | 需要的机制 |
|---|---|---|---|
| 学新阶段冲掉旧本领 | 无效（B 0.49→0.24） | 部分有效，但学得变慢 | **交错复习**：已解决，B 最后 0.67/0.70、C 0.57/0.67（两个种子）；将来由海马体回放旧经历提供 |
| 一次学会新名字 | 无效（7 次都是 0） | 无效 | 通用的"补全门"（强制打开 → 0.60） |
| 没人教时开着学习回答变坏 | 无效 | 只能变慢 | "对方是否及时回应 + 轮次角色"的第三因子 |
| 睡眠回放有害 | 无效 | 按预测误差优先回放后不再有害 | 更强的旧记忆回放 |
