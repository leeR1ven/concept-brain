# v2：新一代架构的设计与原型（进行中）

最终目标：能实时学习的人工智能架构。当前实例：听别人说话，通过肌肉回答，边对话边学。

## 这一轮做了什么
1. **整体审查**（`docs/review/`）：5 个不同背景的审查（神经科学、学习与记忆、发育心理、AI 理论、怀疑者）
   回答同一组问题——"和真实人脑有哪些区别""整个架构有哪些问题""该优先改什么"。
   共识见 `docs/review/SYNTHESIS.md`。要点：
   - 身体部分（轮流说话、按拍发音、会停）保留；
   - 旧架构里会学习的部分没有接到行为上，没有学出来的表征，老师一走就不学；
   - 学习规则要加：预测误差、学来的抑制、联想区"一起亮就加强"、资格痕迹 + 全脑"奖励/意外"信号；
   - 海马体改成"一次记住、记得久、会回放"；训练改成像孩子学说话的分阶段小世界，不再推嘴。
2. **共享测试台**（`bench/`，`python3 bench/selftest.py`，29 项自检）：有场景的小世界，5 个阶段
   （A 听和咿呀、B 看着物体命名、C 句型带空位、D 关系和记忆、E 成人对话）、三种教法（示范 / 改说 / 推嘴）、
   防作弊基线（重复问句、查表、n-gram、先验、神谕）、与旧 v1 逐拍一致的参考智能体（"基准线"）。
   **生活模式**（`bench/life.py`，自检 38 项）：一个智能体从出生一直活下去，不重置、不冻结副本；有白天、到访、独处、夜晚
   （不当作睡眠）、自己变化的场景、背景对话；可随时主动说话（合适就有回应和奖励）；宠物名、人名、东西放哪会不定期反复出现，
   记忆按"间隔 × 经历次数"评分。旧 v1 在生活中只学会打招呼和固定应答，看图题接近瞎猜，记忆为 0，从不主动说话。
3. **三个独立的完整设计和原型**（都不推嘴：发音靠咿呀学语找到，说什么靠听别人回答学会）：
   - `brainlike/`：照真实大脑分区（背侧复述通路、腹侧理解通路、多层前额叶、基底节闸门、海马体）。
   - `develop/`：照孩子的发育顺序（先听、再咿呀、再模仿和改说；有序句子缓存、组合单元、复制闸门）。
   - `predictive/`：一条统一的局部预测误差规则贯穿全脑（规则单元测试 9/9；学会的轮流说话 Go/NoGo；咿呀记忆让后来听到的新字直接会说）。

## 参数搜索（最终结果，`tune/report.md`；约 150 次运行，3 个搜索种子 + 2 个从未用过的种子确认）
- 推荐设置 = develop 默认值 + 交错课程（第二段 B:C=1:1，第三段 B:C:D=1:1:2）+ 清醒回忆（每个安静时刻回忆 8 段，在全部记忆里均匀抽取）+ 一万格海马体。
- 综合分 0.42 → 0.73；在从未用过的种子上 0.34 → 0.74。机制始终 0 错误。
- 阶段间遗忘消失：B 的保持 −0.19 → +0.07，C −0.14 → +0.06。
- 无人教时的漂移减轻约三分之二（C 0.46→0.01 变为 0.58→0.38），只有"清醒回忆 + 足够大的记忆库"有效。
- 任何全局权重衰减都有害；成熟、分裂没有净收益。生活模式里回忆让只经历过一次的内容答对率 0.14 → 0.30–0.33。
- 没解决（需要新机制）：没教过的组合泛化仍低、颜色题在先验水平、一次学会新名字为 0。

## "说话由想法引起"实验（`think/report.md`）
- 把固定的"别人说完第 4 拍起动"换成由想法产生的说话意图（把握度累积到门槛 → 基底节式闸门 → 开口），保留"别人在说就不开口"的刹车。
- 内容：没有提高（B/C/D 0.56/0.61/0.48 对 0.54/0.62/0.48），因为原设计的思考只要 3 步，本来就放得进旧定时器留的时间。
- 时机：难题、没学过的题、答错的题都说得更晚；把握度能预测对错（把握高时 98% 对，低时 34–39%）；不再"别人说一句就接一句"。
- 主动性：生活模式里学会了对方到来时先打招呼（106 次，越来越多），但还不会主动说出看到的东西的名字。
- 风险：想法触发的开口可能落在任何时刻，需要几条先天反射才能保持零抢话。

## 开放仿真世界 world2（`bench/world2/`，自检 25 项）
24×24 的房子加花园（厨房、卧室、客厅、花园），最多 64 个模型一起生活、从不重置；妈妈、爸爸、奶奶三位看护人每句话都按当下情况生成
（指物命名、提问、"去拿X""把X给我""过来"、记忆题、彼此聊天），并回应任何主动说话的模型。每个模型有嘴（真实声音物理）和 9 个
没有预设含义的动作（走、转身、拿、放/给、吃），共享声场（越近越响、隔墙变弱）、以自己为中心的 5×5 视野、触觉、味觉、饥饿和奖励。
支持一个模型批量驱动很多身体。可选"中央凹"眼睛（`eye_mode='fovea'`）：正前方一格看得最细，周围 8 格只看大类和颜色，外圈只知道"有东西/有人/在动/被指着"，模型要转身才能看清（只靠眼睛的参考智能体能把被指的东西转到视野中央 67%，随机 12%）。复读和查表在新情境题、没教过的题、记忆题和请求上都是 0，全知参照全部 1.0；16 个空模型约每秒 12 万拍。

## 统一架构 ARCH_v2（`synth/ARCH_v2.md`，英文完整说明；中文摘要在文末）
以参数搜索的最佳设置为底，每次只加一个部分，至少 2 个种子比较，留下有用的、去掉没用的：
- **保留**：由想法引起的说话意图（基底节闸门 + 先天刹车 + 第 7 条反射"想法至少持续 10 拍才主动开口"）、新字补绑、
  **连续的想法**（别人的话进来时旧内容被挤弱，不清空、不重载；安静很久会走向最熟悉的话题）、先天的视网膜式注意、
  海马体回忆偏向最近的事。
- **去掉**：固定的慢上下文层（摘除后名字题 0.45→0.86，说明它有害）。
- **试过但不采用**：耳朵上层学局部感受野、按"意外度"决定话是否进入想法、保留上一句残留、"说出看到的东西"目标。

| 指标 | 参数搜索最佳 | **ARCH_v2** |
|---|---|---|
| 综合分 J（种子 0–2） | 0.73 | **0.83**（每个种子都更好） |
| 综合分 J（从未用过的种子 3–4） | 0.74 | **0.82** |
| 颜色题 / 数量题 | 0.15 / 0.45 | **0.93 / 0.76** |
| 名字回忆 | 0.44 | **0.76** |
| 一生模式（10⁶ 拍）：自由回答 / 新场景题 / 社交 | 0.20 / 0.25 / 0.06 | **0.34 / 0.33 / 0.32** |
| 一生模式：最后十分之一的答对率 | 0.25 | **0.47** |
| 主动说话 | 无 | 约 1,900 次，其中 347 次先打招呼得到回应 |
| 抢话、发音错误 | 0 | **0** |

- 摘除实验：读出层、焦点、注意、比较器、复制闸门、海马体、清醒回忆（防漂移的关键：去掉后无人教时 0.77→0.01）、
  学来的"别人要说话"刹车都影响行为；"说话热情"V_go 是乘客，可以去掉。
- 代价："这是X吗"0.73→0.63。
- 还没解决：无人教时的漂移只减轻没消除；"多想"还不能提高答案（思考操作是固定的，需要学会控制思考）；
  主动说话多是对方常说的开头；一次学会新名字、跨到访的记忆约 0；没教过的组合泛化约 0.2。
- **第二轮整体审查（`../docs/review2/SYNTHESIS.md`）给这些数字打了折：**
  - 一生模式的自由回答 0.34，还不如"重复对方 / 按题型固定答一句"的简单办法（0.51）；
  - "最爱话题"其实是"是、这、什么"这类虚字；
  - 颜色题的提升主要来自世界给的眼睛编码。
- 审查找到的共同根源是：边听边学时不分"谁在回答谁"，把"自己回答后对方说的下一句"当成答案。
  一个局部修正在一个种子上让综合分 0.70→0.93，无人教时的下降 0.43→0.03（还要更多种子确认）。
- 已写好 GPU 批量移植计划（一张 V100 约跑 64 个身体）；world2 冒烟测试跑通（4 个模型 1.5 天，0 次抢话），
  但移植时要给听觉加增益控制（world2 的声音会衰减和混合）。

## 调参第二轮（`tune2/report.md`，在角色修正前收尾，只做完第一轮）
- **上下文长度。** 推力、门槛、进入增益三个参数其实只决定一件事：想法里同时保留几句话。
  - 要保留多句，必须用"按句龄分开"的键。
  - 按句龄分开并保留 3 句时，"答案在上一句"的测试从 0.13 升到 1.00，"在上上句"从 0.12 升到 0.94，综合分不变差。代价是组合单元多 33%。
  - 用"装一袋"的键保留 3 句，综合分降 0.09，3 个种子都变差。
- **偏爱的念头。** 和公平基准（按听到次数）比，现在的"偏爱"不超过词频，主要是虚词。
  - 加一个局部的"中心归一化"后，安静后的想法会落到具体内容上，而且每个个体不同：一个是香蕉、小狗，另一个是饼干、西瓜、小狗。也没有塌缩。
  - 但偏爱的念头仍然进不了说话。
- **敏感常数。** 都在平台上。只有"说话急迫度"太低（0.05）会让模型在没人反馈时不开口。
- **局部连接。** 预检发现，耳朵三维布局上相邻的音节并不更像，所以要等学出来的词编码层再测。
- **照"只测不学"量。** 综合分 0.77→0.97，没见过的组合 0.30→0.57。这证实了审查的结论：之前分数低主要是学偏，不是不会推广。

## ARCH_v2.1：分清"谁在说话"（`v21/report.md`，第二轮审查计划的第 0–3 步）
- **第 0 步，诚实测量。** 没教过的组合在训练中完全不出现，只在冻结的副本上测。
  - 这样测，ARCH_v2 的泛化分 H 是 0.60，不是 0.20；综合分是 1.00。旧的 H 主要测到的是"学偏"。
  - 但在没教过的题上，它只和"每种题固定答一句"打平（0.55 对 0.54）。
  - 没人教 300 / 900 段对话后，成绩下降 0.30 / 0.54。
- **第 1 步，分角色地边听边学（保留，主要成果）。** 一句话"当答案学"的改变，先挂在突触的资格迹上，等弄清它的角色再定：
  - 我接着回答了它，或者别人马上回答了它：它是问题，撤销；
  - 它带着奖励、紧跟在我的话之后：它是反馈或复述，保留；
  - 自己说的话也以"自己"的身份进入想法。
  - 5 个种子：综合分 1.00→1.23（每个种子都提高），H 0.60→0.76；没人教 900 段后几乎不再学偏（0.54→0.01）；礼貌用语和颜色不受损。
- **第 2 步，听懂的能说出来（保留）。** 加一条按句型开门的通道："说出我认出的东西 / 它在哪"。没教过的"这是什么"0.61→0.81，"在哪里"0.81→0.90，"左边是什么"0.13→0.43。
- **第 3 步，有正有负的价值回路（为"一生"保留）。** 价值低时不主动开口；说了没人理就"失望"；加上粗略的社交感知（有没有人、有人来、有人走）。
  - 一生中对空房间说"你好"：每十分之一生 60–80 次 → 5–9 次；
  - 合适的主动说话 0.19→0.38（最后十分之一 0.46）；社交回答 0.32→0.41–0.43；
  - 代价：测试台综合分比只做 1、2 步低约 0.08，主要是"是不是"题。
- **ARCH_v2.1 = 1+2+3 步**，5 个种子综合分 0.996→1.18（每个种子都提高）；修好视觉缓存后 1.22（4 个种子）。
- **没解决：** 一生中的答题准确率没有提高（0.34），仍低于"鹦鹉学舌或固定答一句"（0.62）。原因是孩子在大人纠正后多半马上接着说话，纠正被当成"问题"撤销了。下一步要能分辨"纠正"和"下一个问题"。

## 出生就有随机连接（`randmix/report.md`，设计者的想法，IDEAS 第 5 条）
- 把"遇到新组合才加单元"的组合层，换成"出生时就全部存在的随机连接层"，再在上面训练、修剪。大小固定，不再增长。
- **最好的形式：每种组合类型分到一样多的随机单元，再加上"用进废退"的修剪和重新生长。** 和 ARCH_v2 按种子配对比较：
  - 标准测试，综合分 0.83→0.95，4/4 个种子更好；
  - 只测不学的真实泛化测试，1.00→1.09，5/5 个种子更好；
  - 没教过的题按题型（真实泛化测试）："能吃吗"0.11→0.64，"给你"0.60→0.92，"在哪"0.69→0.90，"是什么"0.38→0.49；
  - 代价是颜色题 0.95→0.68。
- **"先多长 1.5 倍、再剪"**，最后只剩约四分之一的单元，成绩持平或略好（+0.03–0.07，在单个种子的噪声内，但每个种子方向一致）。
- **单靠随机不行。** 按原比例分配、又不训练的随机层，反而差 0.05；放大到 4 倍、16 倍也没有好处。
- **没改善：** 听错一个字照样损失约三成，没人教时照样遗忘，也学不会按意思推广。
- **注意：** 部分对照在本机、部分在 A800 上跑，numpy 版本不同，单个种子有约 0.07 的平台噪声（见显卡版移植）。"平均分配"的提升（约 +0.1，每个种子都为正）大于这个噪声。

## 显卡版移植（`gpuport/report.md`）
- **结果完全一致。** ARCH_v2 改写成 torch 批量版后，和 numpy 原版逐位相同：种子 0 共 25,934 拍、种子 1 共 185,817 拍，每一拍的每个量都一样；5 个种子的短版流程和第一阶段完整规模也都一样。唯一改动是海马体齿状回 k-WTA 遇到平局时按编号取。
- **原版本身依赖平台。** numpy 版本、Python 版本不同，结果就会分叉。只改平局规则，单个种子的综合分就变动最多 0.07（5 个种子平均 0.825→0.807）。所以单个种子相差 0.03 以内不能算差别，比较必须用多个种子。
- **发现一个小毛病。** 视觉识别有缓存，有时会用过期的结果。v2.1 应修掉。
- **速度没达标。** 64 个个体同时跑，每秒约 250 拍，目标是 3 万。现在的模型每件事计算量太小，而且必须按顺序做（清醒回忆占 70%），显卡发挥不出来。现阶段扫参用 A800 的 CPU 跑 numpy 更划算；显卡版留给放大后的模型（上百万组合单元、更大的海马体）。
- 批量扫参模式能用，结果和单独跑完全相同。
