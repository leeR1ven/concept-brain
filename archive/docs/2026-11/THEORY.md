# 理论：这个架构为什么能学会规律，参数怎么定

目标：在训练之前，用推导加上不需要训练的正向计算，证明架构可行，并定出全部参数。每个结论都写明前提；每个前提都在真实网络上核对（`theory/` 下的脚本，只用正向计算）。

## 0. 模型的正式定义

每一拍 t，所有神经元只有 0 / 1 两种状态。

**输入。** 各区（听觉、视觉、触觉、肌肉力度、阻断、概念）所有特征神经元的副本，统一记为 x_t ∈ {0,1}^n，不分来源（设计者 11-04）。x_t 由各区上一拍的状态经链式神经元一对一复制而来。

**前额叶（四层）**
- 第一层：L1_t = x_t ∨ y_t。其中 y_t 是从内部点亮的副本，即"想法"。
- 想法的推动：d_t = G·a_{t−1} + W·a_{t−1}。
  - a 是最后一层的状态；
  - G 是出生时固定的回路（最后一层 → 第一层）；
  - W 是学习到的读出连接。
- 想法：y_t = [d_t − u_t > θ] ∧ top_m(d_t − u_t)。
  - u 是每个副本自己的"平时水平"，按时间常数 τ 跟随它平时收到的推动；
  - m = κ·n̄，κ 是兴奋度，n̄ 是平时外部输入的数量。
- 中间层（固定，不学习）：L2_t = [F₂·L1_{t−1} > θ₂]，L3_t = [F₃·L2_{t−1} > θ₃]。
  - 每个神经元接附近的 K 个输入，权重在 U(0.5, 1.5) 中随机取；
  - 门槛按各自收到的信号定，使亮的比例为 ρ_mid。
- 最后一层：a_t = top_{|L1_{t−1}|}( F₄·L3_{t−1} + g·V·a_{t−1} − u⁴_t )。
  - V 是最后一层内部学到的连接；
  - 每个神经元收到的内部总推动 g·Σ_j V_ij ≤ σ_in，σ_in 是出生时输入推动在各神经元间的差别。

**学习（同一条局部规则）**
- W_ij 增加：最后一层 i 在前几拍亮着，第一层 j 这一拍从外部新亮、且上一拍没有被想到。增加量为 η·φ(W_ij)，φ(w) = 1/(1+w)，即越大越难再长。
- W_ij 减少：i 重新亮起时，j 还亮着但没有新亮。
- V 按同一规则学习；海马体按自己的快速规则学习。
- 每 200 拍统一降权一次：w ← w − (1−γ)·w·φ(w)。

**海马体**
- 自己的神经元：s_t = top_{k_h}( R·H1_{t−1} + U·s_{t−1} − u^s )。
- 回忆：h_t = top_m( Q·s_{t−1} − u^h )。
- H1_t = x_t ∨ h_t。

**回程。** 想法和回忆 r_t = y_t ∨ h_t，经回程使各区对应的神经元下一拍亮起。对感觉区，这就是内心的声音和想象的画面；对运动区，就是意图变成动作。所以，说话就是前额叶预测出下一刻的肌肉副本。

## 1. 固定传播路径：同一个东西的编码是否一致，不同东西是否分得开

记号：两个编码的重叠 = 共同亮的数量 / √(各自数量之积)；碰巧重叠的水平等于亮的比例。

**引理 1（单层的重叠映射）。** 一层里每个神经元接 K 个输入，权重独立取自 U(0.5, 1.5)，门槛按各自收到的信号定，使亮的比例为 ρ_out。设输入彼此独立、亮的比例为 ρ_in，两个输入编码的重叠为 q。则输出重叠 q_out 可以精确算出：对每个神经元枚举它的 2^K 种输入子集和 4^K 种成对状态，再对神经元取平均（`theory/overlap_map.py`）。

**核对**（新生小号，每层取信号到达的那一拍；本机正向计算，`core/theory1.py tick=1`）：

| 层 | 算出（同一字两次 / 换声音 / 前接不同字 / 不同字） | 实测 |
|---|---|---|
| 第 2 层 | 0.80 / 0.51 / 0.69 / 0.37 | 0.77 / 0.49 / 0.62 / 0.26 |
| 第 3 层 | 0.82 / 0.58 / 0.72 / 0.47 | 0.82 / 0.65 / 0.72 / 0.43 |
| 最后一层 | 0.49 / 0.18 / 0.33 / 0.10 | 0.71 / 0.41 / 0.56 / 0.19 |

- 门槛各自定的两层（第 2、3 层），公式和实测基本吻合。
- 最后一层是全层挑最强的那些，"只接附近、附近一起亮"的影响不能忽略，公式低估一半。
- 后面只需要最后一层的两个数：一致程度 c、不同东西的重叠 o。它们在出生时由固定网络决定，对真实网络做正向计算即可精确得到，不需要训练。

**出生时的值**（小号，单拍）：c 在同一声音时为 0.71，前接不同字时为 0.56，换声音时为 0.41；o = 0.19。最后一层每拍亮的比例约 1.5%。

## 2. 读出定理：听到 A，B 的推动高于其他所有字

**设定。**
- 前文 C 取上一个字。N(C, j) 是训练中字 j 紧跟在 C 后面的次数。
- 提示 A 时，最后一层的编码里，能连到副本 j 的亮神经元有 k_p 个。

**前提。**
- (A1) 这 k_p 个神经元，每个以概率 c 曾出现在 A 以前的编码里；以概率 o 出现在任一其他前文的编码里；彼此独立。
- (A2) 读出连接与共同出现的次数成正比（线性计数）。凹形增长见下面的注。
- (A3) 每个副本的平时水平，等于它在各种前文下推动的平均。

**定理 2。** 在 (A1)–(A3) 下，对任一其他字 X：

P( X 的推动 ≥ B 的推动 ) ≤ exp( −S² / (2V + ⅔·M·S) )

其中
- S = k_p (c − o)(N(A,B) − N(A,X))；
- V = k_p [ o(1−o) Σ_{C≠A} (N(C,B) − N(C,X))² + c(1−c)(N(A,B) − N(A,X))² ]；
- M = max_C |N(C,B) − N(C,X)|。

对所有 X 求和，就得到"B 不是推动最大者"的概率上界。

**证明。**
1. 每个神经元 i 对 B、X 推动之差的贡献是 Σ_C β_iC (N(C,B) − N(C,X))。β_iA ~ Bernoulli(c)，其余 β_iC ~ Bernoulli(o)，全部独立。
2. 减去平时水平（A3）后，均值为 (c − o)(N(A,B) − N(A,X))。
3. 对 k_p 个神经元求和，得到一组独立、有界（|·| ≤ M）的项之和，均值为 S，方差为 V。
4. 由 Bernstein 不等式得证。□

**推论（与训练时长无关）。** 听得越多，N 按同一比例放大，S、√V、M 也同比例放大，所以上界不变。干扰来自编码之间的重叠，不会因为听得多而减少，只由 c、o、k_p 和语言本身的统计决定。

**推论（需要的连接数）。** 令上界 ≤ δ，得 k_p ≥ ln(候选字数/δ) / min_X e_X，其中 e_X 是 k_p = 1 时的指数。

**用语料算出**（`theory/readout.py`，最常见的 20 对搭配，δ = 5%）：

| c（o = 0.19） | 需要的 k_p（中位数） | k_p = 128 时达标的对数 | k_p = 512 时 |
|---|---|---|---|
| 0.71 | 164 | 16 / 20 | 16 / 20 |
| 0.56 | 315 | 11 / 20 | 16 / 20 |
| 0.41 | 847 | 0 / 20 | 15 / 20 |

- 有 3 对永远达不到，因为 B 不是 A 后面最常见的字（我 → 们、这 → 个、好 → 看）。读出给出的是最常跟在后面的那个，这是预期行为。功能测试应只用"B 是 A 后面最常见的字"的搭配。
- 还有 1 对（是 → 我）B 虽是最常见的后续字，但只占 5%，和第二名几乎一样多，需要的 k_p 上万。
- 现在的大号大脑，k_p = 每拍亮的最后一层神经元数（约 500–1700）× 连接覆盖比例（0.059）≈ 30–100。按定理不够，需要扩大读出连接的覆盖范围，或者提高一致程度 c、降低重叠 o。

**注（凹形增长）。** 实际连接按 w = g(次数) 增长，g 是凹函数（越大越难长）。在典型次数附近线性化后，每个字的推动乘以 g'(该字的典型次数)。出现越频繁的字被压得越多，这对 B 胜过高频字有利。所以线性计数的结论偏保守。这一点还要用实际的 g 核对。

### 2.2 精确计算：不训练，直接算出"听完整个语料后"读出学到了什么

定理 2 假设重叠是随机、处处相同的。实测不是这样：相似的字重叠更多，去掉"什么都亮"的公共部分后，不同字之间仍重叠 0.15，是随机水平的 10 倍。所以不再假设，直接算。

**方法**（`core/theory2.py` 存下编码，`theory/readout_exact.py` 计算，全部是正向计算）：
1. 用出生时的固定网络，对语料最常见的 600 个字，算出：
   - 最后一层的编码（B 将要到来的那几拍）；
   - 每个字从外部点亮的副本。
2. 赫布学习就是计数。只要训练中编码不变（前提 4），听完语料后的读出连接是：
   W = g( Σ_{A,B} N(A,B) · code(A) ⊗ copies(B) ) ∘ 存在的连接，
   其中 g 是规则的增长曲线（越大越难长：w = √(1+2ηn) − 1）。
3. 用每个字的另一次编码（耳朵噪声不同）去提示，每个副本减去平时水平。按副本平均分给每个字打分，看最高分是不是"A 后面最常见的字"。按前文出现频率加权。

**结果**（小号；600 个字覆盖语料 92%；"永远猜最常见的字"为 9.9%）：

| 编码 | 读出连接 | 学习规则 | 预测对 | 前 5 名 |
|---|---|---|---|---|
| 出生时真实编码 | 现在的范围 | 原规则 | 2% | 2% |
| 出生时真实编码 | 全连 | 原规则 | 2% | 2–3% |
| 出生时真实编码 | 全连 | **协方差** | **14%** | 23% |
| 出生时真实编码 | 现在的范围 | 协方差 | 3.5% | 11% |
| 随机编码（同样大小） | 全连 | 原规则（计数 / 越大越难长） | 30% / 40% | 35% / 54% |
| 随机编码 | 全连 | **协方差** | **60%** | **86%** |

**结论（只靠计算得出）：**
1. 原规则加上出生时的真实编码，读出等于瞎猜，练多久都一样。这正是 Cabannes 等（2024）证明的"溢出"：编码彼此太像，能可靠存的对应关系远少于要存的。
2. **学习规则要用协方差形式：** 前后两侧都只记"比平时多亮"的部分，很少一起出现的变成负连接（抑制）。这对应架构里"很少一起亮的神经元互相抑制"，现在的代码没实现。
3. **读出连接的覆盖范围要大：** 只连附近会损失大半。
4. **"越大越难长"优于单纯计数**（30% → 40%），与 Cabannes 等（2024）"按频率次线性加权更好"的结论一致。
5. **差距的原因还没有分解清楚：** 随机编码 60%，真实编码 14%。但对照不干净：随机编码的提示和训练用的是同一份（一致程度 1.0），真实编码是另一次听到的（一致程度 0.78）。所以这个差距不能全算在"不同字太像"头上，要分别量出一致程度和重叠各占多少。

**这个计算本身的简化（尚未核对）：**
- 前文只取上一个字，且是安静后单独听到的，不是连续语流中的状态；
- 编码用出生时的值，平时水平为 0，学习中编码会变；
- 把 B 的全部副本都算成由 A 的编码学到。实测最后一层在声音开始后第 4 拍才首次亮（小号：+4 拍 187 个，+5 拍 116 个，+6 拍 59 个），而 B 的第一批副本也在 +4 拍到达，所以实际只有 B 较晚到达的副本能从 A 的编码学到；
- 输出打分用字的副本平均值，不是模型真实的"挑最强的 m 个"。

## 3. 稳定性：最后一层的编码由输入决定，不被内部连接带跑

**引理 3（挑最强 k 个时的敏感度）。** 设每个神经元的输入推动为 f_i，再加上内部推动 r_i，|r_i| ≤ ρ。一个神经元在加推动前后"一个被挑中、一个没被挑中"，它的 f_i 必在第 k 大的推动 θ 的 ±2ρ 以内（θ 本身最多移动 ρ）。因此，无论内部推动怎样，编码中至少保留

k − min( #{挑中且 f_i ≤ θ + 2ρ}, #{未挑中且 f_i ≥ θ − 2ρ} )

个神经元，它们完全由输入决定。证明：挑中的数量固定为 k，进来一个就要出去一个，只有门槛两侧 ±2ρ 内的神经元可能交换。□

**用出生时最后一层的真实输入推动算出**（`theory/stability.py`；小号，每拍亮 1.5%，输入推动在各神经元间的差别 σ = 1.38）：

| ρ / σ | 0.005 | 0.01 | 0.02 | 0.05 | 0.1 | 0.2 | 0.5 | 1.0 |
|---|---|---|---|---|---|---|---|---|
| 保证由输入决定的比例 | 0.98 | 0.95 | 0.89 | 0.75 | 0.57 | 0.42 | 0.34 | 0.33 |

**结论：**
- 要保证至少 80% 的编码由输入决定（定理 2 需要一致程度 c 高），内部连接的总推动上限应约为 **0.03σ**。
- 之前设的上限 ρ = σ 只能保证 33%。这个界是最坏情况，但按严格标准应取 0.03σ。
- 内部连接因此只能在门槛附近轻微偏向相关的神经元，不能主导最后一层。

## 5. 连续输入：最后一层什么时候知道刚听到了什么

设计者 11-04 明确：模型不是认字，而是不停接收连续的信息，慢慢学会世界的规律。所以这一节不用标签训练读出，也不让字单独出现。标签只用来打分。

做法：出生时的网络（`s=1`，自身不学习）连续听 1000 段对话，共 25283 个字，959 种，每对相邻的字平均听 1.8 次。把最后一层和输入副本的活动逐拍录下（`theory/stream_record.py`），读出在录像上算（`theory/stream_fit.py`、`stream_id.py`）。测试句分听过的和没听过的，各有原顺序和打乱顺序。每个字的打分是从最常听到的 100 个字里选一个。

**时间差。** 选"刚听到的是哪个字"，原顺序的句子（只猜最常见的字约 4%）：

| 这个字开始后第几拍 | 最后一层选对 |
|---|---|
| +3（下一个字开始） | 约 5% |
| +4 | 40–43% |
| +5 | 49–55% |
| +6 | 48–52% |
| +7 | 28–35% |
| +8 | 约 9% |

信号到最后一层要 4 拍，而一个字只有 3 拍。所以"最后一层上一拍 → 这一拍新亮的副本"这条连接，在下一个字刚开始时拿不到上一个字的信息。这是第一轮测试（`theory/stream_probe.py`）看不出顺序的主要原因：那轮的分数还被上一个字的回响稀释，连理想读者也几乎没有差距，所以不能算"没学到"。

**下一个字。** 目标改为下一个字开始后第 3 拍新亮的副本，这时最后一层已经知道上一个字。回归只在这些拍上训练：

| | 听过的句子 | 没听过的句子 |
|---|---|---|
| 只猜最常见的字（原顺序） | 5.1% | 5.8% |
| 最后一层，原顺序 / 打乱 | 10.9% / 7.2% | 9.2% / 4.9% |
| 差（百分点） | +3.9 ± 1.5 | +3.2 ± 1.1 |
| 理想读者（知道当前的字，数过相邻字对），原顺序 / 打乱 | 20.8% / 5.7% | 18.3% / 3.1% |

**这个结果的限度：**
- 这是一个迹象，不是证明。差约 3 个标准误，而且是在几种时刻、时间差和 λ 里看到的最好一组（λ=1000），有挑选偏差，要换数据确认。
- 用的是岭回归，不是模型真实的学习规则，只说明最后一层带有这部分信息。
- 约为理想读者的四分之一。网络没有学习，只听了 1000 段。

**下一步：** 把每个字放慢到 6 拍再测（`theory/stream_slow.py`），然后在录像上跑真实的学习规则。
