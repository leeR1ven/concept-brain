## 0. 结论

1. **能证明的等价。** "最后一层 → 下一刻第一层"的读出，和大语言模型的输出层做的是同一件事：用状态 h 预测下一个输入 x′。精确地说（定理 2.3）：带分级预测误差的局部规则 ΔW = η·a·(x − ŷ)ᵀ 是平方损失在输出层的一步随机梯度，即反向传播在最后一层所做的那一步；二值形式（"已预测不加强、预测了没来减弱"）是它的感知机式近似。纯赫布计数读出等于把二元组计数用最后一层编码的重叠做核平滑（定理 2.2），只在各前文编码正交时等于训练到最好的读出。**整个网络不等价**：大语言模型的中间层是训练出来的，这里的中间层固定。延迟不破坏回路：A 的最后一层编码出现在第 +4..+6 拍，B 的副本在第 +4..+7 拍到达，两种配对规则（代码的、设计者 11-04 的）都把它们配上（命题 2.1）。
2. **算出的事实（300 个常见字，每字 3 个人声各听 6 次，共 18 次；新听到的做测试；`multi.py`、`lookup.py`、`proto.py`）。**
   - 计数读出（现在代码的规则）预测下一个字 11.6%，等于不看前文（11.1%），**与听多少次无关**（定理 2 的核太平：其他前文的权重是本字的 500 倍）。
   - 带预测误差的读出（定理 3，收敛后 = 岭回归）取决于降权的强弱：降权弱时 7–17%，降权强（λ = 30–300）时 **31–32%**（按前文平均）/ **22–27%**（单次新听到做提示）；第四个人声 18–20%。岭系数就是降权与学习率之比，是设计者的"一个统一降权"。计数读出的各种加权（原始、按前文归一、开方）都停在 11–12%；只有带预测误差的规则能超过它。
   - 信息在编码里：用外部标签算出每个字的类均值再最近邻认字，18 次时认出 38%，认出后查"最常见的后续"得 **40%**；副本层（前额叶的输入）更高：认出 53%，查表 54%。这只说明信息**在**，不说明脑里有哪个局部机制能取出来——脑没有标签。
   - 无标签时：在线赢者通吃原型（竞争式赫布，带"自己赢得太多就让一让"的局部项，无标签）K = 300 / 600 / 1200 个单元时认字 19 / 25 / 30%，经赢者查表 **18 / 18 / 22%**（第四人声 10–11%）；副本层 K = 600：20%。有标签的 40% 里，这个简单的竞争层取出约一半；单元越多越纯（纯度 0.23 → 0.45），还在上升。
   - 字与字的差别超过字自身变化的方向只有约 10 个（Fisher 判据，第 4 节）。
   - **身份丢在听觉区，丢在"越深越稀"上。** 耳朵的输入位就能认出 81% 的字（同样的类均值最近邻），听觉区的四层固定随机局部网络之后只剩 38%，前额叶固定通路再丢到 31%；耳朵的抖动和噪声（世界参数）只占 7 个百分点，关掉结论不变。正向扫描（4.2 节）：听觉各层的亮率是起作用的参数——亮率 ×2 把副本从 51% 拉到 71%（第一层密度 3.6%，仍在设计者要求的 5% 以内），×4 到 75%、最后一层 61%（密度 7.4%，超了）；K 和窗口不起作用。这和 11-03 前额叶中间层的毛病相同：太稀太挑剔。身份和稀疏之间的取舍要设计者定。跨人声在输入位上就只有 33–47%，不变性只能学。
3. **判断。** 架构不是不能工作，但**现在的规格（计数规则 + 固定通路直接读出）在能算的范围内只达到"不看前文"的水平**。要达到"听到 A 想到 B"，两件事都要有，缺一不可：
   - 读出规则带预测误差（设计者在 IDEAS 第 1 条已接受的 v2 规则），并且降权要强到岭回归的最优点附近（第 3b 节；现在的 γ_pfc 几乎不降权，5.4 节）；
   - 读出之前有一个**认字**的阶段——同一个字的不同听到落到同一批神经元上。架构里指定做这件事的是抽象概念区（设计者 11-03）。它能不能做到，本文只有一个无标签的替身实验（18–22%，有标签上限 40%），没有定论；而且它的原料已经被听觉区的固定随机网络从 81% 压到 38%，所以要检验的是"听觉区 + 概念区"合起来能不能把认出率拉回输入位的水平。这是训练前最后一个要用正向计算回答的问题（4.3 节给判据）。
4. 其他部分：想法名额按平时输入算（已改）是对的；最后一层内部连接的上限 cap = 1.61 = 0.94σ **挡不住锁死**：150 段对话后不同字的最后一层编码重叠从 0.25 升到 0.77（无 cap 0.86；cap = 0.08 时 0.48，好一半，没解决；5.1 节）；名额大小（23 个）的想法在最后一层留下的编码认不出是哪个字（与真听到的重叠 0.07，随机 0.03），所以 κ = 0.1 下想法接不上想法（5.2 节）；海马体编码的一致程度（同一句两次 0.35，随机 0.0025）由输入副本的一致性和稀疏度决定，与扇入无关（第 6 节）；回程把想法送回感觉区再进来，在计数规则下是正反馈、在预测误差规则下自洽，不需要堵回程，但"已被想到"的门要盖住回声的 2 拍延迟（2.4 节）。
5. 参数表第 7 节；可证伪的预测第 8 节；与上一版的差异第 9 节。

## 1. 模型的精确定义（含时间）

每拍 t 所有神经元为 0/1。一个音节持续 3 拍，第 τ 个音节占耳朵的 3τ, 3τ+1, 3τ+2 拍。

- 副本 x_t ∈ {0,1}^n（n = 8701，各区特征神经元的一对一副本，不分来源）。听觉区第 l 层比耳朵晚 l 拍，副本再晚 1 拍：一个音节的副本从起音后 +1 拍开始新亮，到 +4 拍（实测每拍新亮 179、179、184、141 个，`codes.py`）。
- 想法 y_t：从内部点亮的副本。第一层 L1_t = x_t ∨ y_t。
- 中间层固定：L2_t = [F₂L1_{t−1} > θ₂]，L3_t = [F₃L2_{t−1} > θ₃]，各自门槛使亮的比例为 30%。
- 最后一层 a_t = top_{|L1_{t−1}|}(F₄L3_{t−1} + g·V·a_{t−1} − u⁴)。V 是学到的内部连接，进入一个神经元的总推动有上限 cap。
- 想法的推动 d_t = (G + W)·a_{t−1}，G 是出生回路，W 是学到的读出。y_t = top_m(d_t − u) ∧ [d_t − u > θ₁]，m = κ·n̄，n̄ 是平时的外部副本数（实测 229），κ = 0.1，m = 23。
- 回程：y_t 经回程让各自的源神经元在 t+1 拍亮，源神经元的状态在 t+2 拍作为 x_{t+2} 收进来。海马体回忆 h_t 走同一条回程。
- **学习规则，两个版本。** *代码的规则*（`core/net.py`）：副本 j 在 t 拍从外部新亮且上一拍没被想到；最后一层 i 在 t 拍亮，或最后一次亮在 t−1、t−2、t−3 拍（fall_win = 2）；则 W_ij += η·φ(W_ij)，φ(w) = 1/(1+w)。*设计者 11-04 的规则*（`ARCHITECTURE.md` 四，代码还没改）：B 亮起时 A **刚亮或刚灭**才加强；一直亮着的 A 不加强；同时亮的不互相加强。"刚"有几拍长，没有规定，下文按 1 拍（A 在 t−1 拍新亮或在 t−1 拍熄灭）分析，并说明 2 拍时的差别。

**固定通路的延迟（实测，s=1 新生，`codes.py`）：** 起音后副本 +1，L2 +2，L3 +3，最后一层 +4（265 个）、+5（156）、+6（63）、+7（13）。安静时前额叶各层 0 个亮。最后一层每拍新亮 / 熄灭：第 4 拍 264 / 6，第 5 拍 78 / 187，第 6 拍 30 / 122，第 7 拍 5 / 56。

**本文各结果在哪条规则下成立。** 第 3 节的读出计算用的前件编码是"第 4..6 拍亮过的并集"。单独听一个字时最后一层事先全暗，所以每个亮过的神经元都恰好"刚亮"过一次、之后"刚灭"一次：刚亮事件的并集 = 亮过的并集（368.6 对 368.8 个，一致程度、认出率完全相同，`codes600` 核对）。因此第 3、4 节的数字在两条规则下都成立；两条规则的差别只在连续语流里前件配到哪一拍（2.1）。第 5.1 节的探针用的是代码的规则。

## 2. 等价性：精确陈述、证明、以及它在哪里失效

### 2.1 命题 1（时序对齐）

**陈述。** 连续语流中，第 τ 个音节的最后一层编码在 3τ+4..3τ+6 拍（第 4 拍几乎全是新亮，第 5、6 拍主要是熄灭）；第 τ+1 个音节的副本在 3τ+4..3τ+7 拍新亮。

*代码的规则*（窗口 {t, t−1, t−2, t−3}）：第 τ+1 个音节在 3τ+4 拍新亮的副本配到 a_{3τ+4}（音节 τ 第 4 拍）∪ a_{3τ+1..3τ+3}（音节 τ−1 的第 4..6 拍）；在 3τ+5、3τ+6 拍新亮的配到音节 τ 的编码加音节 τ−1 的尾巴；在 3τ+7 拍新亮的配到音节 τ 的编码 ∪ 音节 τ+1 自己的第 4 拍编码（自联想）。

*设计者的规则*（A 在 t−1 拍刚亮或刚灭）：在 3τ+4 拍新亮的副本（179 个）配到 3τ+3 拍的事件 = 音节 τ−1 的最后熄灭（约 56 个）；在 3τ+5 拍新亮的（179 个）配到 3τ+4 拍的事件 = **音节 τ 的第 4 拍新亮（264 个）**，这是主配对；在 3τ+6 拍新亮的（184 个）配到 3τ+5 拍的事件 = 音节 τ 第 5 拍的新亮（78）和熄灭（187）；在 3τ+7 拍新亮的（141 个）配到 3τ+6 拍的事件 = 音节 τ 第 6 拍的新亮（30）和熄灭（122）。同时亮的不配，所以自联想没有了。

**证明。** 把延迟、事件计数和各自的窗口代入。□

**推论。** (a) 两条规则下读出学的都是 h_τ → x_{τ+1}，h_τ 是 x_τ 经固定网络的像："用当前状态预测下一个音节"。(b) 代码的规则窗口 4 拍 > 音节 3 拍，前件是**两个音节的并集**（无序二元前文）；设计者的规则下上一个音节只经它的熄灭事件（约 56 个神经元）进入，前件基本是一个音节，**两音节并集这一点在新规则下不再成立**。"刚"取 2 拍时，上一个音节的第 5、6 拍熄灭（187 + 122）也会进来，前件又变成一个半音节——这是"刚"的长度这个参数的后果。(c) 新规则下 B 的第一拍副本（179 个，占 B 副本的 26%）配到的是上一个音节的尾巴，不是 A 的编码；A 的编码只教 B 后三拍的副本。(d) 即使 V = 0，最后一层编码也带着上一个字的尾巴（上一个字的副本在它起音后 +4、+5 拍还有 155、53 个亮着）。实测（120 字）：同一字前接两个不同的字，第 4 拍编码彼此重叠 0.45，单独听时 0.41；第 5 拍 0.60 / 0.60（同一字换噪声 0.80 / 0.73，不同字 0.27 / 0.22）。

**概念区的矛盾（只标出，不解决）。** 架构里抽象概念区的文字靠的是同时亮："经常一起出现、或上下文相同的东西编码变得相近""和边缘的局部神经元同时亮而连起来"（设计者 11-03）；而 11-04 的规则说同时亮的不互相加强。两者不能同时成立，需要设计者裁定概念区用哪条。

### 2.2 定理 2（赫布计数读出 = 用编码重叠做核的二元组平滑）

**记号。** S 个前文；训练时前文 C 第 e 次听到的最后一层编码 h_{C,e} ∈ {0,1}^n；N(C, X) 是 X 紧跟 C 的次数；copies(X) 是 X 从外部点亮的副本集合；H 是以各 h_{C,e} 为行的矩阵，Π 是各行的频率权重，Ȳ_C = Σ_X N(C,X)·copies(X)/N(C,·)。

**陈述。** 全连接、计数规则得到 W_H = HᵀΠȲ（差一个常数）。提示编码 h 时，副本 j 的推动

  d_j = Σ_{C,e} K(h, h_{C,e}) π_{C,e} Ȳ_{C,j}，  K(h, h′) = |h ∩ h′|。

即**计数读出 = 二元组计数按最后一层编码的重叠加权平均**（不归一的核回归）。平时水平减去的是 Σ π K(·, h_{C,e}) 这一项。最小二乘解 W* = (HᵀΠH + λI)⁻¹HᵀΠȲ，故 W_H = (HᵀΠH + λI)·W*，两者只差常数当且仅当 HᵀΠH 在 H 的行空间上正比于单位阵（各编码正交、按 π 等长）。λ → ∞ 时 W* → W_H/λ：**降权无限强的预测误差规则退化成计数规则**。

**证明。** 展开定义。□ 这是 `docs/EQUIVALENCE.md` 的"近乎正交"前提，它是充要的。

### 2.3 定理 3（预测误差规则 = 输出层的随机梯度 = 反向传播的最后一层那一步）

**规则。** ΔW_ij = η·a_i·(x_j − ŷ_j) − η·λ·W_ij：a_i 最后一层 i 是否亮；x_j 副本 j 是否从外部亮；ŷ_j 是 j 收到的内部推动 d_j（分级）；λ 是降权。三个量都在突触两端可得。

**陈述（精确到什么程度）。** (i) 分级形式是损失 ½‖x − Wᵀa‖² + ½λ‖W‖² 对 W 的一步随机梯度，正是反向传播在输出层所做的那一步（输出层误差 δ = x − ŷ，不往回传）；步长 η < 2/λ_max(HᵀΠH) 时收敛到岭回归解 W*(λ)。(ii) 大语言模型用 softmax 交叉熵，输出层梯度 a·(x − softmax(Wᵀa))ᵀ，形式相同但误差是归一化概率之差；这里的 top-m 选择与 softmax 的关系是类比，不是等式。(iii) 把 ŷ 换成二值（j 是否被想到），规则变成感知机式：预测了没来 → 减弱，没预测却来了 → 加强，预测对了不变；这是另一条规则，有自己的收敛定理（线性可分时有限步收敛），不是 (i)。(iv) 以上都只说输出层；中间层固定，全网络不等价于训练过的大语言模型。

**证明。** ∂/∂W [½‖x − Wᵀa‖² + ½λ‖W‖²] = −a(x − Wᵀa)ᵀ + λW；收敛条件是 Widrow–Hoff 的标准结果。□

设计者在 IDEAS 第 1 条说的"v2 的带预测误差的规则在单层上正是反向传播最后一层那一步"，按 (i) 是对的。现在代码只有"已预测不再加强"，缺"预测了没来 → 减弱"，权重不能为负，所以现在的规则属于定理 2 的计数，不属于定理 3。

### 2.4 自由运行的回路

- **周期。** 想法 y_t 由 a_{t−1} 推动；y 进入 L1，3 拍后到最后一层，再 1 拍成为下一个想法：内部回路周期 4 拍（听的时候 3 拍一个音节）。经回程：想法 t → 源神经元 t+1 → 副本 x_{t+2} → 最后一层 t+5 → 想法 t+6，周期 6 拍。两条回路并存。
- **增益。** 最后一层亮的数量等于上一拍第一层的数量。安静中只有想法亮（m = 23），最后一层也只能挑 23 个；中间层门槛按 229 个输入定。想法能不能喂下一个想法，实测见 5.2。
- **从自己的想法学习（分析，不是禁令）。** 回程点亮的源神经元在 t+2 拍作为 x 进来。两种来源要分开：
  1. *前额叶自己的回声*（想法 → 回程 → 副本）。计数规则下这是正反馈：被预测的 B 回来时若上一拍没被想到（想法只闪一拍时常见），就按"外界新亮"记一次 N(A,B)，与世界无关；预测越强回声越多。预测误差规则下，回声到达时 ŷ 仍预测着 B（想法持续）→ 误差 0 → 不学；想法已闪灭时按"没预测却来了"学一次，但同一条规则稍后会以"预测了没来"减回去（世界不跟进时），没有净正反馈。结论：**不必堵回程**，要换的是计数规则。此外"上一拍没被想到"这个门只盖 1 拍，回声要 2 拍才回来；把门改成"最近 2 拍内没被想到"（副本自己的局部年龄）就把回声完全盖住，是局部改动。
  2. *海马体回忆*（h → 回程 → 感觉区 → 副本）。按架构，长期记忆正是靠皮层从反复回忆里慢慢学会。回忆带来的副本是前额叶没预测到的，在预测误差规则下恰好被学进读出；这就是巩固，应当保留。
  两者的区别在局部可得：前额叶自己的回声是"刚被想到的副本"，回忆不是。

## 4. 最后一层的编码必须满足什么；固定通路给不给

### 4.1 要求

读出是编码的函数。两个前文的编码若分不开，它们的后续就被平均。要求是：**同一个前文在不同噪声、人声、F0、音量、邻居下的编码变化，要小于它和其他前文编码的差别**。度量用"类间方差 / 类内方差"（Fisher 判据），按方向数。

### 4.2 实测（`multi.py`，300 字 × 18 次）

| | 类间 > 类内的方向数（6 次 / 18 次） | 类间 > 3×类内 | 前 4 个方向的比值 |
|---|---|---|---|
| 最后一层 | 9 / 10 | 3 | 18.6、8.8、5.8、3.0 |
| 副本层 | 10 / 10 | 5 | 9.3、10.6、5.1、3.2 |

- 上一版的"有效维度 14"是单次编码的参与比，量的是方差集中度，撤回；换成上表。
- 单次编码的认错里只有 8–18% 是同一个字的另一个声调，所以不是声调编码弱，是整个字分不开。
- 把最后一层挑得更稀（每拍只留 1/2、1/4、1/10）不改善（`kernel2.py`）。
- 信息在副本层已经有损失，固定通路再损失约 15 个百分点（有标签认出：副本层 53%、最后一层 38%）。

Cabannes、Dohmatob、Bietti（2024）研究的是各向同性随机嵌入的外积联想记忆，容量随嵌入维度走；把这里的"可用方向数 ≈ 10"对应到他们的维度是**我的推断**，不是他们的结论。

### 4.3 谁来解决、怎么检验

出处更正：上一版把"输入要学出特征""中间层也要学"归给设计者，**错了**：IDEAS 第 3、5 条里这些话在"补充"和实现记录里，是之前的助手写的；设计者自己的想法（第 5 条）是"随机网络，相似输入激活相似输出，这就够了，再赫布连接"，`ARCHITECTURE.md` 规定中间层不学。

4.2 的分层结果说明损失主要在听觉区的固定随机局部网络（81% → 38%），不在前额叶；所以"固定随机网络给不给可认的编码"这个问题的答案是：耳朵给了，听觉区没传下来。架构里**指定**学不变性的地方是抽象概念区（设计者 11-03："语速、音色、音高不同，只要激活同一批概念神经元，就是同一个意思"），它的副本是前额叶第一层的一部分。所以不是加新层，而是检验概念区。3b 的无标签原型实验就是概念区的一个替身（竞争 + 赫布，无标签）：它取出 18%，有标签上限 40%。真正的检验（正向计算 + 一次短学习）：让带概念区的脑听 1 万段，冻结，对 300 字 × 多人声记录概念区副本，算 4.2 的方向数和认出率。**判据（我给的目标，不是定理）：第四人声认出 ≥ 50%，类间 > 类内的方向数 ≥ 100。** 本文没有做这一步：概念区现在会卡住最后一层（体检 11-03），要先修；而且它的学习规则与 11-04 的新规则有 2.1 末尾所说的矛盾。

## 5. 稳定性：内部连接、想法回路、回程

### 5.1 最后一层内部连接（`stability.py`，float32 推动；`cap_probe.py`）

两种 σ：模型算 cap 时用每个神经元减去自己时间均值后的差别（1.61，对应平时水平 u⁴ 的作用）；本文按同样定义算出 1.72（音节第 4..6 拍），不减均值是 2.11。下表按减均值的 σ；第 k 大的推动比平均高 2.29σ。内部连接给一个神经元最多加 ρ：

| ρ/σ | 0.05 | 0.1 | 0.2 | 0.3 | 0.5 | 1.0 | 2.0 |
|---|---|---|---|---|---|---|---|
| 最坏情况保证保留（引理，推动落在门槛附近） | 0.67 | 0.45 | 0.19 | 0.08 | 0.02 | 0 | 0 |
| 典型模型保留（推动落在与输入无关的 k 个神经元上） | 1.00 | 0.99 | 0.98 | 0.98 | 0.96 | 0.89 | 0.74 |

- cap = 1.61 = 0.94σ：典型模型 89%，最坏 0。两个模型都不对：学到的内部连接推的是**刚才一起亮过的神经元**，它们和当前输入既不独立也不是故意对抗；语流里上一个字的状态和这个字的输入部分相关。真实值只能实测。
- 无上限时的锁死是实测事实：7.9 万段后内部推动约 3000（≈ 1700σ），安静 4 拍后同一句两次最后一层重叠 0.00；同一字重叠从出生 0.74 降到 0.27。
- **短学习探针（150 段对话 ≈ 1.8 万拍，s=1，代码的规则，20 个常见字，单独听后第 4..6 拍的最后一层编码；`cap_probe.py`）：**

| | 同一字换噪声 | 换人 | **不同字** | 密度 | 内部推动（亮的神经元上的均值） |
|---|---|---|---|---|---|
| 出生 | 0.77 | 0.55 | 0.25 | 0.036 | 0 |
| 150 段后，cap = 1.61 | 0.89 | 0.81 | **0.77** | 0.037 | 1.14（0.66σ） |
| 150 段后，无 cap | 0.95 | 0.91 | **0.86** | 0.037 | 10.8（6σ） |

| 150 段后，cap = 0.08（0.05σ） | 0.77 | 0.64 | **0.48** | 0.054 | 0.24（超过 cap：cap 只在每 200 拍降权时施加） |

  **结论：审查者对了，我错了。** 学到的内部连接推的不是随机的神经元，而是一批经常一起亮的神经元；它们被推过门槛后对什么字都亮，不同字的重叠从 0.25 升到 0.77，"同一字 − 不同字"的余量从 0.52 缩到 0.12。cap = 1.61（0.94σ）挡不住，和无 cap 只差一点。这是引理的最坏情况，不是典型模型。**保留 cap = 1.61 的说法撤回。** 按引理取 cap = 0.08（0.05σ）后余量 0.29：好一半，没有解决；cap 两次施加之间权重超限 3 倍。平时水平 u⁴（τ = 1000 拍）没有抵消这股推动，因为学习比它快。根本原因是内部连接学的就是"一起亮过的互相推"，这正是设计者 11-04 规则删掉的那一项；新规则下这部分连接应当少得多，要重测。

### 5.2 想法回路（`chain.py`，正向计算）

把一个字的 23（名额）/ 180（一拍真听到的量）/ 全部副本当想法点亮 2 拍（回程开，新生，20 个字），之后各拍回声副本数（经回程回到感觉区再进来的副本）、最后一层数量、与真听到时编码的重叠（随机 0.029）：

| 想法大小 | 回声副本（+2 拍起，逐拍） | 最后一层数量 | 最后一层与真听到的重叠 |
|---|---|---|---|
| 23（名额） | 23、30、14、5、1 | 23、30、14、5 | 0.07、0.08、0.04 |
| 180 | 180、213、111、32、6 | 180、213、111、32 | 0.41、0.41、0.36、0.19 |
| 全部（638） | 639、795、718、557、298 | 642、796、723、570、302 | 0.56、0.54、0.56、0.52 |

  回声不放大（23 → 30 → 14 → 5，两拍后熄灭），所以想法的数量就是它在最后一层留下的编码大小；名额大小的想法在最后一层留下 23 个神经元、与真听到的编码重叠 0.07（随机的 2.4 倍），**根本认不出是哪个字**，更推不动下一个想法。要想法能接想法，想法要有一拍真听到的量（180：重叠 0.41）以上。即 κ ≈ 0.8 而不是 0.1，或者最后一层的数量不跟着第一层缩。这是旋钮（设计者："安静时安静是正常的"），但"连续思考""独处时自己思考"在 κ = 0.1 下不可能发生，这是算出的后果。

### 5.3 回程

回程强度 g_ret = 1.05 × 源神经元门槛：一条回程单独点亮它的源神经元，不多不少。回声副本在 t+2 拍进来。学习上的后果见 2.4。

### 5.4 读出权重的平衡值

每次事件 Δw = η φ(w)，每 200 拍降权 Δw = −(1−γ)·w·φ(w)。事件率 r（每拍）时平衡 w* = 200·η·r/(1−γ)。γ_pfc = 0.99995 → w* = 8×10⁴·r：每 1 万拍一次的搭配平衡在 w* = 8，但凹形增长到 8 需要 (9² − 1)/(2η) = 2000 次事件，整个语料（约 10⁷ 拍）里多数连接到不了平衡，权重 ≈ √(2η·次数)。所以 `docs/EQUIVALENCE.md` 前提 2"权重与频率成正比"在现在的 γ 下不成立，降权在前额叶几乎不起作用（体检：降权快 10 倍无差别，一致）。而 3b 说预测误差读出需要**明显的**降权（λ ≈ 10 对应于每次事件的学习量）：现在的 γ 离那里很远，要改。

## 6. 海马体（`hippo.py`）

每个海马神经元随机接 rec_fan = 24 个副本，权重 U(0.5, 1.5)，每拍挑最强的 kh = 50 个（nh = 20000）。副本密度 0.078（听的那一拍），每个神经元平均 0.7 条亮输入。我原先猜"抽样噪声压死一致性，扇入要加大"，**算出来不是**：

| 扇入 | 平均亮输入 | 同一字换噪声（kh=50 / 200 / 800） | 换人 | 不同字 | 随机水平 |
|---|---|---|---|---|---|
| 24 | 0.7 | 0.35 / 0.43 / 0.53 | 0.08 / 0.13 / 0.21 | 0.08 / 0.12 / 0.20 | 0.0025 / 0.01 / 0.04 |
| 96 | 3.0 | 0.31 / 0.37 / 0.46 | 0.06 / 0.11 / 0.18 | 0.06 / 0.10 / 0.17 | 同上 |
| 768 | 23.8 | 0.27 / 0.33 / 0.43 | 0.05 / 0.09 / 0.17 | 0.05 / 0.08 / 0.15 | 同上 |

（输入副本本身：同一字换噪声 Jaccard 0.60，换人 0.25，不同字 0.19。）

**推导。** 推动 D = Σ w·x 是输入的线性和；同一事件两次的 (D, D′) 的相关系数 r 等于输入的相关系数，与扇入无关。挑最强 k/N 的集合两次重合的比例是尾部条件概率 P(D′ 在前 k/N | D 在前 k/N)。Jaccard 0.60 → 共有份额 q = 2J/(1+J) = 0.75 → r = (q − 密度)/(1 − 密度) = 0.72。二元正态下：

| r | 0.72 | 0.80 | 0.90 | 0.95 |
|---|---|---|---|---|
| kh/nh = 0.25% | 0.22 | 0.31 | 0.49 | 0.62 |
| 1% | 0.29 | 0.38 | 0.54 | 0.67 |
| 4% | 0.40 | 0.48 | 0.62 | 0.73 |

实测（扇入 768）0.27 / 0.33 / 0.43，与公式差 0.05 以内。**结论：海马体编码的一致程度只由输入副本的一致程度和稀疏度决定。越稀疏分得越开（不同字 0.08 对同一字 0.35），同一事件也越认不出。** 要让同一句两次落到 80% 同一批神经元，0.25% 稀疏时输入相关要 ≈ 0.98。瓶颈仍在进入前额叶和海马体之前的编码一致性。体检里的 17% 比这里的 35% 低，差额来自活着的脑里平时水平、学到的内部连接和多拍状态的叠加，未分解。

回忆连接的容量（Willshaw 型、裁剪权重，算出的上限）：P ≈ ln2·(可用连接数)/(kh·m) = ln2·20000·2000/(50·23) ≈ 2.4×10⁴ 个"海马状态 → 下一拍副本"的关联；γ_hip = 0.99（每 200 拍）的 e 折时间 2×10⁴ 拍 ≈ 半小时（按一拍 ≈ 80 ms）。没有实测。

## 8. 可证伪的预测

1. **按现规格训练**（计数规则、固定通路）：听完全部语料后，单独听 A，想法里 B 的份额与"永远想最常见的字"无差别；只有 3d 列出的高份额对（ha1→ha1、shen2→me5、ke2→yi3 …）能过。
2. **只改规则**（加"预测了没来 → 减弱"，降权调到 λ ≈ 30–300，θ₁ 降到 0.3）：300 个常见字的 A→B top-1 在 22–32% 之间（单次提示 22–27%），第四个人声 ≤ 20%；降权不改时 ≤ 17%。
3. **概念区检验**（4.3）：若概念区学过之后第四人声认出 ≥ 50%、可用方向 ≥ 100，则预测误差规则的 A→B 应 ≥ 50%（随机编码对照 89%）；若只有无标签原型的水平（赢者纯度 0.34），A→B 不超过 20%。
4. **海马体**：改扇入不改变同一句两次的海马编码一致程度（±0.05）；kh 从 50 加到 800 升到约 0.5；只有输入副本更一致才能超过 0.6。
5. **回声**：计数规则下，单独听 A 再安静 20 拍，想法闪烁的那些拍里 W(A→B) 增长；预测误差规则下不增长。
6. **cap**（已测，预测落空一半）：我预测 cap = 0.08（0.05σ）时 150 段后"同一字 − 不同字"余量仍 ≥ 0.4；实测 0.29（同一字 0.77、不同字 0.48；出生 0.52；cap = 1.61 时 0.12；无 cap 0.09）。cap 只能减缓一半：不同字的重叠仍从 0.25 升到 0.48。原因之一：cap 只在每 200 拍降权时才施加，两次之间权重超过上限 3 倍（亮的神经元上的内部推动 0.24 > 0.08）。所以单靠 cap 不够，要么每拍施加，要么内部连接的学习本身（一起亮过的互相推）要按 11-04 的新规则改（同时亮的不加强）——新规则下这部分连接会少很多，这是一个可以正向验证的预测。

## 9. 和上一版结论的差异，以及本版撤回的说法

| 上一版 / 本版初稿 | 现在 |
|---|---|
| 等价性只在近乎正交时成立（当作前提） | 近乎正交是计数读出等价的充要条件（定理 2）；分级预测误差规则等于输出层的梯度步（定理 3(i)）；二值形式是感知机式近似；全网络不等价 |
| 延迟是未处理的漏洞 | 延迟使 A 的编码和 B 的副本相邻拍到达，两条规则都配得上（命题 1）；代码规则下前件是两个音节的并集，新规则下不是 |
| 2% / 14% / 60%：规则是主因 | 计数规则在任何训练量下等于不看前文；预测误差规则 + 合适的降权在 18 次时 29% / 20%；信息在编码里（有标签 40%），无标签竞争层取出 18% |
| 本版初稿："最小二乘 13%、线性上限 55%、编码是极限" | 撤回：单次过拟合；多次听到后随降权上升 |
| 本版初稿："有效维度 14" | 撤回：单次参与比；换成类间/类内方向数 ≈ 10 |
| 本版初稿："设计者提出学出特征层" | 撤回：那是之前助手的补充；设计者指定的是概念区 |
| 本版初稿："回程不能触发学习" | 撤回：计数规则下是正反馈，预测误差规则下自洽；回忆经回程学习是设计的巩固 |
| 定理 2 的 k_p 需求（164–847） | 前提 A1（重叠随机、均匀）不成立，数字作废 |
| 内部连接上限应 0.03σ | 探针证实最坏情况才是真实情形：cap = 0.94σ 时 150 段后不同字重叠 0.77；上一版的 0.03σ 量级是对的，本版初稿的"典型模型保留 89%、可留"撤回 |
| 海马体未分析 | 一致程度 = 尾部条件概率，由输入一致性和稀疏度决定，与扇入无关 |
