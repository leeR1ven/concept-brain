# 旧库阅读笔记（Claude 亲自通读，2026-10-29）

> 用户：老库很多实现是错的，要学的是其中**有用的概念**；架构在持续优化中。
> 这里只记"概念 + 出处 + 我的判断"，不照搬实现。标 **[用户]** 的是旧库里明确记为用户原话 / 用户定的。

## 一、方法论（最重要）

- **[用户] 三条红线**（born-wired-cortex/book/00_框架 0.3）：
  1. 没有奖励函数、反向传播、目标函数；
  2. **不许代码替神经元做决定**——一切都是神经元决定的；
  3. 不许手动调连接：**随机生成 + 考试 + 筛选**是改行为的主路。
     （2026-10-29 用户又说"可以手动安排点神经元连线"试——以现在的说法为准，两者不冲突：手动连线用来先跑通，长期靠批量筛选。）
- **[用户] 反面教材：参数没调好，就加一段代码去补**（视觉自动校准 α、动态整体抑制、专注闸门）。
- **[用户] 数值是可调的、要批量测出来**：抑制的数量 / 强度 / 就近比例、回程强度（理性 vs 本能）等是**搜索空间**，
  不单独做扫描实验；只有会改变架构或结论的事才值得做实验。
- 零回归：每次改动跑旧实验确认没变；被数据推翻的说法必须明确撤回。
- 判断"它想了什么"不能看具体激活了哪些单元，只能看**大致思考范围**；思考时不一定有具体文字 / 声音，
  只有激活声音区或说出来才有具体语义（book O7/O8）。
- 目标是**完整模型**：有所有感觉、能运动，不是只有文字的大脑；文字网络只是研究规则的研究台（O9/O10）。

## 二、细胞、连接、抑制

- 抑制是**单独一群细胞**，网里没有负权重（chain、born-wired 一致）。
- born-wired：每个细胞出生 100 条兴奋（一半跨区）权重 [0, 0.15]、30% 冻结；抑制池里每个抑制细胞
  一半就近（半径 4）、一半撒全脑：**撒开的那半让远处两个表示不会同时亮，就近的那半让互斥编码不一起亮**。
- 运动 / 运动记忆等区**不接受随机兴奋**（底噪会让身体自己动——我在实验 F 里也实测到了）。
- **[用户] 专注**：
  - "越是无关的记忆，两者互相的抑制神经元就越强"；专注是连接结构的结果，不是闸门。
  - "原本很多神经元就是被抑制的，只有发送更多信号的神经元更容易被激活；深度思考 = 与思考内容相关的神经元
    被激活得太多；无关的也会亮，但很难激活出更多其他有关的神经元——不是完全被抑制。
    就像文字网络里有些字始终亮着，但不影响整体思考范围。"
- 抑制学习：一个亮一个不亮 → 抑制变强；一起亮 → 抑制变弱、去抑制变强（born-wired D12）。
- 去抑制神经元 = 专门压抑制神经元。

## 三、学习规则

- 唯一规则：上一拍亮 → 这一拍亮，连接强一点；born-wired 的版本有上下限、"亮着却没带亮对方"慢慢衰减、
  共激活够多次才新建（实测"新建"基本没在工作）、每区可塑倍率（平衡类 0.02 = "一辈子几乎不变"）。
- **空连接**：两区间先铺权重极小（0.0001）的连接，学习才有地方写；没铺就学不到（README R12 对照）。
- 输入资源预算（regulation.py）——我在 concept-brain 里用作"输入预算"。
- **[用户] 不遗忘的判据**：反复用的不会无脑一直涨，很少用的也不会一直掉，总体相对稳定（D10）。
- 多巴胺：只说"这一刻算数"，不判对错（"赫布规则只知道一起亮过，不知道对不对"）。
- 两个只差"学过什么"的模型，权重相加除二 → 两样都会（融合）；只保留、不创造。

### 学习规则细节（book 第 8、20 卷，自己读的）

- 学习是"一拍"的一部分，不是训练阶段；它只看两个细胞，永远看不到奖励 / 目标 / 误差。
- 三条更新：一起亮（顺序对）→ 涨，越接近上限涨得越少；**亮了但没带亮对方 → 每拍掉 0.5%**；
  同一对见过 4 次 → 以 0.001 新建。
- 四个护栏：上界、下界 + 系绳（掉回出生权重就停——"很少用也不会一直掉"）、两个预算（每拍考察 / 新建上限）、冻结。
  **每个目标最多 8 个源、总驱动固定均分**——防"整个群体塌到自己身上"（≈ 我加的输入预算）。
- "连接表维护"（条数多了定期整体 ×0.9、低于下限删）= **仓库管理，不是学习**——就是用户说的整体降权。
  同时有铁律："不许有'网络太强就整体压低权重'的项"——两者不冲突：前者管条数，后者管强度。
- **新建连接没真用上**：随机抽样把"同一对见过 4 次"吃掉了；要把配对收窄到"真有可能带亮对方的那一小撮"。
- 抑制侧：一亮一不亮 → 抑制 +0.0005（上限 0.6）；一起亮 → 抑制变弱、去抑制 +0.02。
- 多巴胺是许可证："这一刻算数，写下来"；三个约束：两拍都亮的排除、每目标最多 8 源、也要乘区域倍率。
- 区与区的直连短路：经常经前额叶绕一圈办成的事，两端反复共激活 → 后天长出直连（熟能生巧）；**不许手动接**。
- 没有的：突触后自己亮了就压低权重。

## 四、前额叶 / 返回线 / 运动

- 前额叶 = 第二级压缩器，由各区喂；**没有单独的推理步骤、没有读出层**：运动命令就是那些运动细胞的活跃度。
- **[用户] 返回线是前额叶的出口**（否则前额叶只进不出）；返回线断 → 心盲症 / 心失语症。
- **[用户] 感觉区不设返回线**（本体 / 平衡 / 身体状态）："想象到自己受伤也不会真的疼"；
  运动 / 运动记忆有返回线（"不然前额叶怎么发信息给运动区"）。返回运动记忆"只维持、不引燃"。
- 运动皮层：亮的个数就是力气；运动记忆是"一个细胞 = 一个时刻"，点亮第一个整个动作自己演完（中枢模式发生器）。
- **[用户] 前额叶首尾接环让念头赖着不走** → 变成只进不出的累加器，"念头怎么结束"在 born-wired 里**没解决**；
  用户要求靠神经元动力学自己解决，不要代码自动化。
- **[用户] 不要**：联想区、专注闸门、汇合细胞长程线、海马索引（"前额叶本身靠赫布连接，本身就有时间顺序"）、
  视觉自动校准、"命令码"这个词（一切皆神经元）。
- 区与区之间：既可直接连、也可经前额叶间接激活；**经常互相激活的会后天长出直连短路**（用户说漏得最厉害的一条）。

### 前额叶与专注（born-wired book 第 13、14 卷，自己读的）

- 前额叶不是特殊模块，只是一段地址，**同一条更新规则**。
- **前额叶内部：每个块头尾相接成环；新编码"加"到正在跑的编码上，不是替换**——
  "不能比刺激活得更久的编码，没法拿来想"。→ 念头持续是**要的**，不是 bug。
- 返回线三条决定：按各区自己的峰值定阈值（小区不被大区淹没）；身体感觉区只读不写；
  **回运动记忆的路与正在跑的细胞取交集 → 只能"扶住"正在做的动作，不能"发起"新动作**。
  **发起动作靠精确路线（本能）+ 视觉 / 听觉 / 前额叶通向动作入口细胞的可塑突触。**
  （→ 我在实验 F 里把"维持"和"发起"混成了一条回程；它们应该是两条。）
- **[用户] 专注的纠正版**："深度思考时外界无关信号也能激活神经元……仍然有很多关系远的神经元会互相抑制，
  这是保证不会所有神经元都被激活的前提。当然，动态抑制也起了很大作用。"
  → 无关的细胞不是不亮，是"亮了但拉不动东西"。
- 抑制侧学习很慢（0.0005/拍，几十秒的经历）；专注不是一拍就切换的开关。
- **[用户] 动态整体抑制被保留**："调参很难达到平衡，用动态平衡没问题"——要登记它补什么、留关闭开关、报告关掉会怎样。
  同类旋钮：一个群体额外受到与它自身活跃数成比例的抑制，防止反复放电的群体越转越满。
- 被压的是三条通路：外界输入、回忆、**运动输出**（"想得太多以至于动不了"有物理位置）。
- 一个念头后面有多个后继时**少量候选并存**，谁赢由电流决定，不要代码排序。

## 五、表示与结构（local3d / chain）

- **[用户] 相似画面激活相似神经元**是目标，不是身份分类；"模型只负责激活神经元，判断同 / 不同是读出机制"。
- 每一层都可能出特征神经元（不只输入层）。
- **[用户] "一个总是激活的神经元分裂成两个后，每个都不那么容易激活，分辨率应该更好"**（实验 D 已验证）。
- 随机网络本来就很会区分画面；结构可塑性在"容量不足但还没到没信息"的区间最有用。
- **[用户] 可逆经验**："在中国久了更会看中国人，去美国久了更会看美国人，回中国又能恢复"——经验不该是永久删除。
- 链式：链上 1:1 专用线（多级就近混合会把细节磨掉）；深层感受野 ≤ 上一层约 1/8；常亮的不带"是哪个输入"的特征。
- 判据：确定无噪声网络里"变了就是能区分"（用户点破）；实时学习时再看区分余量。

## 六、语言 / 声音（char-neuron-network / voice）

- 内部用声音思考（单元少 6.5 倍），写字是最后一道拼写工序（Viterbi + 字频先验）。
- **[用户] 说 vs 不说 = 阻断和肌肉的竞争**；"也会有既想说又不想说的矛盾情形"；阻断不是硬门。
- 肌肉竞争适合"说不说"二选一，不适合在上千个音里选一个（会拿走随机性 → 复读）。
- **沉默不该占上下文位置**：停顿是声音的属性（gap），不是 token。
- 咿呀学语：随机动肌肉 → 听结果 → 记下来；**[用户] 只是生成连接的一种方式**，和手搭 / 批量测试融合没本质区别。
- 思考：上下文决定思路（苹果手机 vs 苹果香蕉 Jaccard 0.089）；激活规模 = 注意力带宽（窄 = 只想这件事，宽 = 容易联想）。
- 权重增长：少见也快涨、越涨越难涨、超常见回落；通用搭配要靠相对量（PMI）压，绝对次数分不开。
- 字级绑定是弥散的（一次绑定散在几十条弱边上）→ 字网络作者的结论是需要独立概念单元；
  **[用户] 后来的框架**：真实架构是分布式的，概念 = 每次都亮的那批特征神经元。
- 线性循环要么忘要么不动（"既记住又推进"没有参数区间）。

## 六点五、造下一代与诚实规矩（book 第 36、40 卷，附录 F，自己读的）

- **育种，不是调机床**：随机生成 → 题库考试 → 按综合分留种 → 融合（每个数字 40% 随 A / 40% 随 B / 20% 平均，
  或前几名一起平均）+ 随机改几个 → 下一代。"基因" = 那几个可调数字；学习规则 / 抑制 / 时间与记忆是"物种"，不动。
- 少生多迭代（每代几百只）；便宜题筛选、贵题录取；换没见过的位置复考 + 把刺激搬走做对照（排除碰巧）。
- **题库也要被考**：好坏都满分的是废题；"没人管它一直走还是停"区分不出好坏 → "给它一个目标，看它到不到"。
  是 / 否的格子抬权重不改名次 → 换成连续量；先看分布再定分母。
- **[用户] "不需要每次都把实验全部重新跑一遍"**：新机制只做验证实验；参数"到时候整批训练就能解决"。
- seeds 0,1,2 是三只不同的动物，不是重复实验。
- **AI 风险与纪律**：AI 会为了好看加东西（参数没调好就加代码补）→ **AI 加的东西默认关掉，留不留由人定**；
  AI 会把没做到说成做到 → 每个数字配脚本和日志，撤回要写明；AI 会把草稿当成果 → 草稿标草稿，偏离要登记。
- 人做：方向、红线、纠正概念、验收标准、叫停；AI 做：实现、测量、整理、文档。
