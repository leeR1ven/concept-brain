# 前额叶和大语言模型做的是同一件事

设计者的论证（归档 `archive/docs/IDEAS.md` 第 1 条）写成证明。

## 两边的结构

**大语言模型（自回归网络）**
- 状态：h_t = F(x_t, h_{t−1})。前文压缩成一个状态。
- 读出：y = W·h_t，挑最大的作为下一个输入；生成时把它当作 x_{t+1}。
- 训练到最好时，输出是"这段前文之后最常出现的下一个输入"，即 P(x_{t+1} | 前文) 最大者。

**这个大脑**
- 第一层 x_t：各区副本，外部点亮的加上想法。
- 最后一层 h_t：F(x_t) + L44·h_{t−1} 里最强的那些。F 是固定的中间层，L44 把上一刻带进来，所以 h_t 含前文。
- 读出 W：最后一层 → 第一层的赫布连接，w_ij ∝ "i 亮完 j 紧接着亮"的次数。
- 想法：推动 Σ_i h_i·w_ij 最大的副本被点亮，成为下一刻的输入。

两边都是：状态 → 读出下一刻的输入 → 当作输入继续。

## 赫布读出等于训练到最好的读出

- 设不同前文 c 在最后一层用的神经元基本不重叠（各自一组 S_c）。
- 副本 j 收到的推动 = Σ_{i∈S_c} w_ij = |S_c| ×（前文 c 之后 j 出现的次数）。
- 推动最大的就是"前文 c 之后最常出现的下一个输入"，与训练到最好的大语言模型相同。
- 矩阵形式：W = Σ_t x_{t+1}·h_tᵀ。各 h 正交时，它与最小二乘解 W* = Y·Hᵀ·(H·Hᵀ)⁻¹ 只差一个比例常数，后者正是反向传播在最后一层收敛到的解。

## 中间层不训练也行

足够多的随机神经元把不同前文映射成不同状态（Cover 定理；回声状态网络、随机特征网络）。L44 和回路把历史带进状态，相当于循环网络的记忆。

## 实时学习

每拍只给"刚亮的 → 接着亮的"加一点，学一次就生效，不用重算整个网络。

## 证明用到的四个前提（模型看起来不对时只查这四条）

1. 不同前文的最后一层状态重叠要小；重叠越大，读出越像"不看前文、只说最常见的"。
2. 连接强度与实际出现频率成比例，不无限累积（统一降权让旧的慢慢淡掉）。
3. 推动最大的那些能真正点亮成想法（11-04：想法名额按平时的外部输入量算；按这一拍算时，安静中名额几乎为零，记住的下一个字点不亮）。
4. 最后一层的状态主要由最近的输入决定（固定随机网络加读出能工作的必要条件：回声状态性质，Jaeger 2001）。同一个 A 每次出现，最后一层要用差不多同一批神经元；内部连接的推动若远大于输入（实测练 3 千段 12 倍，7.9 万段上千倍），这一条就不成立，B 想不起来。所以内部连接总推动设上限，上限等于输入推动在各神经元间的差别，由结构算出。

## 用实际数字算（`core/snr.py`）

信噪比 = (n(A,B) − n(A,X))(1−o) / sqrt((var_B + var_X)/Kp)，o 是不同前文在最后一层的重叠，Kp 是一个副本收到的最后一层亮神经元数。语料最常见的 20 对搭配：

| | o | Kp | 信噪比中位数 | 可靠（>3）的对数 |
|---|---|---|---|---|
| 新生（大号） | 0.19 | 79 | 2.4 | 5 / 20 |
| life2 | 0.10 | 98 | 3.9 | 14 / 20 |
| 新生（小号） | 0.16 | 17 | 1.2 | 0 / 20 |

信噪比与训练时长无关（干扰来自编码重叠，不随数据变少），只由编码结构决定。小号大脑理论上就做不到。
