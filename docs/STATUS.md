# 现状（2026-11-13）

规则只看 [ARCHITECTURE.md](ARCHITECTURE.md)。这里只写现在什么能用、什么在修。以前的实验记录在 [archive/docs/2026-11/](../archive/docs/2026-11/)，只作背景。

## 能用的（已验证）

- **概念区**：同一个音节不管谁说都点亮同一批细胞。完整的活脑听了 17000 段对话后，跨说话人 0.98，每个核心细胞只属于 1.1 个音节。关键是"看到的字"作为第二种感觉，教声音去点亮同一批细胞。
- **前额叶的大致趋势**：在没听过的对话里，真正的下一个音节被排在第一的约 10%，同样的音节打乱顺序时 3–5%。
- **上下文**：句子说完后的空档里，前额叶和海马体仍带着整句的内容。只改句子的第一个字，空档里前额叶 10–20%、海马体 25–40% 的神经元亮得不同。

## 在修的（修好并逐条检查之前不训练）

全模型对照 ARCHITECTURE.md 的独立审查（[archive/docs/2026-11/AUDIT_2026-11-13.md](../archive/docs/2026-11/AUDIT_2026-11-13.md)）发现，运行中的模型有不少地方偏离了规则。按模型的本质逐项改回：

| 项 | 状态 |
|---|---|
| 时序赫布：同时亮的、一直亮着的不加强 | 已改，逐条核对通过 |
| 海马体回忆打开；被回程点亮的内容照常回到前额叶 | 冻结检查：没有回声爆发，可以打开 |
| 所有学到的连接都参加统一降权 | 待改 |
| 运动区按规则重做：想法 → 回程 → 运动神经元和阻断竞争；"说完就停"。去掉临时的"音节池" | 进行中，见下面"运动区"；已停，没有训练 |
| 概念区接收所有感觉（触觉还没进来） | 待改 |
| 前额叶回路撑住想法 | 架构写明现在只靠各层延迟（约 5–6 拍），不算偏离；不另加机制 |
| 肌肉意图不占想法名额（以前加的例外，架构里没有） | 冻结检查：有这个例外时，安静中每两拍点亮 56–206 个杂乱意图，明确想说的字只 10% 说出；去掉后杂乱意图最多 10 个，明确的意图 100% 说对，混合的不说，大人说话时、听到字时都不说 |

**做法（设计者 11-13 晚）：** 旧模型其他部分基本可用，只修运动区，不重做整个模型，已经测过的不再重测。生成器先停在第二步（见最后一节）。

## 运动区（11-13 晚，未完成，按设计者要求已停）

设计者的方向：运动就是把感觉网络反过来用，前额叶的想法经回程重新点亮运动区；全用神经元，不写挑选程序；反过来的连接也遵循差不多的赫布规则。代码：`core/grow.py` 的 `DownLinks`、`motor_reverse`（概念神经元 → 力度神经元的回程连线，从零开始学；孩子在安静中随机咿呀出整个音节，听到自己的声音时学），检查脚本 `core/gen/babble_check.py`（咿呀学语后冻结检查）。

- 普通赫布（同时出现就加强）：权重一直长（最大 42），背景想法就把力度神经元推过门槛，一直说乱码，刹车也停不住。
- 改成"加强到能预测住就停、预测错了就减弱"：权重有界（最大约 0.15）；安静、听到别人说话、刹车时都不出声；但想一个完整音节仍说成乱码（它自己的力度神经元平均只被推到 0.46，别的有的到 0.87）。
- 发现的两个根本问题：
  - 想法很少：对话停顿里每拍只有约 8 个概念神经元被回程点亮，一个音节的概念编码约 150 个。按整个音节学到的连接推不动；改成"按人数平均"又失去"没把握就不说"，背景想法也发力，乱码被触觉感到后又被学进去，越学越乱。
  - 自己的声音和大人的声音在概念区里点亮的几乎是两批神经元：同一音节自己说和大人说重合 0.41，两个不同音节之间也有 0.37（两个大人之间 0.55）。所以咿呀学语学到的"听到自己的 X → 动作 X"用不到从大人那里学来的概念上。
- 停下前准备试的（没有跑完）：世界里家长一半时间跟着重复孩子咿呀出的音；只在听到声音时学（乱码不出声就不学）。

## 生成器（11-13 起；设计者："你要看透这个架构的本质，当你理解透本质后，就能很简单的用生成器做出来这个模型了"）

按设计者 11-11 的本质：没有分区、没有副本；一张按同一条接线公式长出来的树状网络；只有亮和不亮的神经元；全脑一条学习规则；特殊的只有前额叶输出连回输入的回路。代码：`core/gen/grow.py`（接线），`core/gen/t1_sense.py`（第一步），`core/gen/t2b.py`（第二步）。

- **第一步 感觉部分：通过。** 分层、往前传自己长出来（往回连 0.45%，深度和位置相关 0.97）；出生期足够长时各层亮的比例接近目标（14%、11%、10%、6.5%）；相似的声音激活相似的神经元，越深越挑。
- **第二步 两种感官汇合成概念：进行中。** 耳朵、眼睛两条分支相向长，在中间汇合；每个神经元都有出生连接和可学习的连接，同一条规则学习。
  - 每一小片固定比例地亮、按"高出自己平时"竞争（架构 六、二.4）以后，各层亮的比例准确，字在汇合处分得清（同一个字 0.84–0.91，不同的字 0.15–0.21）。
  - 只让汇合处学习时，声音的信息一路丢失（耳朵 0.68 → 最深 0.11 → 汇合处 0.04）。让所有神经元都学：汇合处 0.11–0.15。再按本质加上"少数长轴突"：汇合处 0.4–0.5，同一个音节换嗓音和不同音节的差距 0.05 → 0.17。
  - 还没成：看到字还没有教会声音，学 3000 段同一个音节换嗓音只到约 0.6（目标 0.9 以上）。下一步先想清楚本质里"另一种感官怎样把同一个音节的不同嗓音绑在一起"，再改，不再逐个试参数。
