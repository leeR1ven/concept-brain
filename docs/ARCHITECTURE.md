# 架构（唯一权威版本）

> 本文只写规则。设计者新说的话和本文冲突时，以设计者为准，并更新本文。
> 实验经过、讨论和旧版全文都在 `archive/`，只作背景，不是规则。
> 版本：2026-11-10。

## 一、组成

用纯神经元搭一个像人一样一直活着、一直学习的大脑：
- 感觉区：听觉、视觉、触觉（含肌肉力度）；
- 抽象概念区；
- 前额叶（思考和预测）；
- 海马体（短期记忆）；
- 杏仁核（先天价值）；
- 运动区：只通过肌肉输出。

全脑只有一条局部赫布学习规则和一个统一降权。能力来自经历，不为某种能力专门写程序。

## 二、神经元和网络（所有区用同一种方式生成）

1. 神经元只有亮和不亮两种状态。抑制神经元就是输出权重为负的普通神经元。
2. 编码是分布式的：一个东西激活很多神经元，没有"一个字一个神经元"。
3. 输入层用温度计正反对编码：每对恰好亮一个，所以输入层永远一半亮。什么都没有也是一个读数。
4. **每个区的网络都用同一种方式生成：** 立体、局部、随机。
   - 每个神经元只接上一层附近的几个神经元，按 y、z 算远近。出生时的权重固定。
   - 每个神经元的门槛按它自己收到的信号来定。
   - 这样相似的输入激活相似的神经元。
5. 感觉区越往后的层亮得越少。前额叶输入多少、输出多少：最后一层亮的数量等于输入层；中间层不用管。
6. 自己和别人的声音激活相似但不同的神经元，不需要标签。

## 三、各区

### 感觉区
- 视觉：中心像素多，边缘少。
- 视觉区前几层额外有局部运动神经元：
  - 上一拍局部神经元 1 亮，激活 A（隔一拍才到）；这一拍旁边的局部神经元 2 亮，2 和 A 一起让 B 亮。B 亮 = 这里有东西往这个方向动。
  - 它们整体互相抑制，所以整个画面都在变时不亮。
  - 出生就连到眼肌，让眼睛自动转过去。
- 触觉区：输入层是每块肌肉实际用的力和皮肤的触碰，其余和其他感觉区一样。
- 抽象概念区：
  - 自己的一群神经元，接收各感觉区的特征神经元，用同一条规则学习。
  - 经常一起出现、或上下文相同的东西，编码会变得相近。
  - **不变性就这样学出来**（设计者 11-03）：在视野中间看到人，"人"的概念神经元亮起；人慢慢移到视野边缘，概念神经元还亮着，就和边缘的局部神经元同时亮而连起来；以后余光看到人，同一批概念神经元也会亮。声音同理：语速、音色、音高不同，只要激活同一批概念神经元，就是同一个或相近的意思。
  - 和其他区一样，用链式神经元连到前额叶和海马体。

### 链式神经元
- 每个区每一层的特征神经元，都一对一地送到前额叶第一层（得到一个"副本"），也送到海马体。
- 每条去程链配一条回程链：副本亮了，经回程让原来那个神经元亮。
- 靠近输入、一直亮着的神经元没有特征：没有链式神经元，也不长连接。哪些算特征神经元，是每个区可调的参数。
- 感觉区神经元分裂或删除时，它的链式神经元和副本跟着增减。

### 前额叶
- **结构是多层循环网络：**
  - 第一层是各区的副本。
  - 中间各层是和其他区同样方式生成的随机局部网络，权重不学习（以后可能分裂和删除神经元）。
  - **层数（设计者 11-09）：** 用够用的最少层数，和真实皮层的 3–4 级相当。层让最后一层和输入有时间差，也把特征组合起来；两层不够："NOT T" 这类答案是两个特征的异或，要中间层先组合（11-09 实测：答题那一刻，两层的最后一层读出答案 0.77–0.85，四层 1.00）。
  - 最后一层这一刻的活动，和下一刻第一层里位置相近的神经元做赫布连接，学"接下来是什么"。
  - 最后一层内部的互相连接也学习：有关的互相激活。
- **出生时有回路：** 最后一层能反过来点亮第一层，把想法保持住。
- **输出就是第一层被内部点亮。** 点亮的来源有三种：预测、回路、海马体回忆（经感觉区回来）。被点亮的副本经回程让感觉区（内心的声音、想象画面）或运动区（意图）的神经元亮起来。
- 回程强度可调，是"理性和本能"的旋钮。回程点亮同一个神经元的强度，要小于点亮下一个内容的连接强度。
- 安静时前额叶照样有输入。
- **抑制：** 正在想的内容会压住无关的东西。很少一起亮的神经元互相抑制，有关的互相激活。
- 兴奋度相当于上下文长度。思考是连续的，不会重开。说话由思考引起，外界信号只影响思考。
- **上下文**：决定下一步想什么、说什么的那一刻，亮着的神经元里还带着多久以前的内容（和"记住"不同，记住在连接里）。它由几样一起决定：能把内容撑住的结构（几样内容同时亮着，靠刚长出的专属连接互相撑着，连接逐拍衰减，旧的退出）、同时能装几样（兴奋度）、每样的信号强弱（稀疏程度和大脑大小）、衰减快慢。现在的前额叶能用的只有各层的延迟，约 5–6 拍，一句话要在这个窗口里说完（11-10 实测，LOGIC.md 6、8）。撑住的结构测过能到 15–21 拍，但会和正在听的词抢位置，暂不开。
- 前额叶的大小和全脑成正比，放大时全脑一起放大。

### 海马体
- 有自己的一群神经元：出生时随机接收各区的副本，内部没有出生回路。
- 内部连接和回忆连接用同一条赫布规则，但长得快、掉得快。
- 每拍亮的数量固定（总激活越多，越难再往上推）。
- 回忆点亮各区里对应的神经元，再由这些区间接影响前额叶，不直接进前额叶。
- 什么都存。相似的信号引起相似的回忆。
- 长期记忆由皮层靠反复回忆慢慢学会。不需要睡眠，没有时间环。

### 运动区和说话
- **只通过肌肉输出。**
  - 每块肌肉有一群力度神经元，亮得越多，力越大。
  - 常亮的阻断神经元管"默认不动"。
  - 平时不亮的停止神经元有链式神经元，"说完就停"和前额叶的"让它停"都学到它们身上。
  - 抑制神经元学到的连接永远是抑制性的。
- **说不说是一场竞争，没有硬门槛。** 没把握时就不说，而不是说错。
- **声音和动作经前额叶连，听觉区不直接连运动区：**
  - 路径是：前额叶最后一层里代表某个声音的神经元 → 第一层里那几块肌肉的力度副本 → 回程 → 力度神经元 → 和阻断神经元竞争。
  - 例外只有两个：
    - 输入层 → 停止神经元的先天刹车：只按附近声音的强弱刹，只能让动作停；
    - 视觉局部运动神经元 → 眼肌。
- **运动区落定：** 第一代手动布置肌肉神经元之间的连接，让混合的倾向落到最强的那个完整音节上，落不下去就不说。
  - 同一个音的肌肉互相激活，按顺序一块接一块；
  - 压住对手音的抑制神经元也在里面。
  - 这组连接会学习、会降权。
- 其他动作走哪条路，由学到的连接决定。接话的时机由模型自己决定。基底节的功能就是运动区的抑制神经元。
- 自己纠正说话靠训练学会：靠听到自己的声音和触觉，再加奖励。

### 杏仁核（先天价值）
- 自己的一群神经元，用链式神经元接收各区信号。出生时就接好，对某一类、某一范围的信号起反应。
- 亮了以后激活和它相连的各区神经元，给出倾向（靠近、停下、注意），也是奖励信号的来源。
- 可以有多个，比如快乐的、恐惧的。
- 学习：同时亮就加强，再由降权留下各次都亮的共同部分。

## 四、学习

- **时序赫布：**
  - B 亮起时 A 刚亮或刚灭，A→B 加强；
  - 一直亮着的 A 碰到 B 亮，相当于一加一减，不加强（设计者 11-04）；
  - A 在 B 之后自己重新亮起，A→B 减弱；
  - B 熄灭不减弱任何连接；
  - 同时亮的不互相加强（设计者 10-29、11-04）。
- **最后一层 → 第一层的连接（学"接下来是什么"），由第一层的副本自己检查（设计者 11-07）：**
  - 副本从外面亮了，最后一层却没把它点亮 → 来自刚才亮着的最后一层神经元的连接加强；
  - 最后一层点亮了它，外面却没亮 → 这些连接减弱；
  - 已经对了就不变。每拍的改动由当时连到它、亮着的神经元平分，步长小。
  - 依据：打砖块里只在副本刚亮起时学，猜对玩家按键 52%；加上"亮着且没被点亮就加强"87%；再加"点亮了却没来就减弱"92%，上手达到所学玩家的水平（docs/GAME_TEST.md）。
  - 其余连接仍用上面这条时序赫布。
- **凹形增长，没有上限：** Δw = η·a_i·a_j / (1 + w/w_ref)^pow。
  - 减弱和降权也按同样的系数变慢。
  - 永远保留约 1% 的可塑性。
- **全脑一个统一降权：**
  - 后天长出的连接定期乘一个系数，太弱的删掉；出生连接不降。
  - 海马体降得最快，越深的层降得越慢。
- 时间就是先后顺序，不需要表示"过了多久"。
- **奖励只是工具（设计者 11-08）：** 做对了加强、做错了削弱最近约 1–2 秒里带出动作倾向的连接（最后一层 → 动作的副本），别的连接不动。这样模型仍然记得做错的事，但不会再做。
  - 每个动作当时亮着的那一组就是它的选择：按着时是"按下组"，不按时是"停止组"（不跳也是一种选择）；
  - 越近的改得越多；难过时也削弱之前因为高兴已经加强过的，所以一路前进最后死掉，那几秒仍算错；
  - 好坏只来自先天价值，回应多少不能判断好坏。
  - 主要靠听别人说来学，奖惩只是偶尔纠正；多奖少罚，只在很有把握却错了时明确惩罚（设计者 11-09）。完全不纠正时，自己说错的话会被当成"接下来是什么"学进去。
  - 记功劳的选择要和动作本身一致：答题按答题那一刻的选择；按住跳键不等于跳（11-09 实测）。
- **结构可塑性（很慢）：** 总是亮的神经元分裂，从不亮的删掉。判据是能不能区分事物。
- 不为某个现象写专门的机制。

## 五、一生、世界和后代

- 一直活着，一直学习，没有睡眠，不按对话重置。小时候允许犯错，不抢话的先天刹车一直保留（只是让它倾向于轮流说，不是硬规定，设计者 11-09）。
- 世界一直在教：大人对"说得接近"也会高兴，这就是奖励。不做跟读训练。
- **训练顺序：**
  1. 第一代在前额叶里手动接好"声音 ↔ 发出它的肌肉"；
  2. 再让模型听大量别人之间的对话；
  3. 想到回答，就会自动说出来。
- 第一代可以手动加连接，每组都要登记。测"能不能学会"时，只用从没手动加过的内容。
- **进化：** 随机生成 → 考试 → 留种 → 繁殖。
  - 繁殖时每个数字 40% 随父、40% 随母、20% 取平均，再随机改一点。
  - 后代带着融合后的连接出生，还要重新学，但学得更快。
  - 价值观是先天的，不参与融合。
- 放大是全脑一起放大。最终成品是纯神经元。

## 六、已定的实现细节（实测得出；要改须有新证据）

- 前额叶最后一层每拍亮的数量等于输入层；海马体每拍亮的数量固定。
- 前额叶中间层亮得多一些（约 30%）。太少时每个神经元太挑剔，同一句话换个声音就被拆成完全不同的反应，句子信息到不了最后一层（11-03 实测：最后一层能认出的句子从 6% 升到 41%，练 1 千段想法就有规律）。
- 想法（第一层从内部点亮）的数量上限按平时的外部输入量算，不按这一拍的；否则安静时名额为零，听到 A 后想起的 B 点不亮（11-04 直接测试）。
- 前额叶最后一层内部学到的连接，进入一个神经元的总推动不超过输入推动在各神经元间的差别（出生时算出，大号约 1.6；超过就整体按比例调小）。否则练久了内部推动是输入的上千倍，状态不再由听到的决定，赫布读出学不到"A 后面是 B"（11-04，见 docs/EQUIVALENCE.md 前提 4）。
- 第一代手动接的连接，按"用熟了"的强度存，否则会被日常学习冲掉。它仍用时序赫布，不用自我检查，否则"想到一个音却没说出口"会把它削弱。
- 第一层副本的自我检查（11-07 实测）：加强一直到推动超过阈值 2 才停，这样该亮的亮得稳；减弱只在真被推过阈值、外面却没来时才做。若减弱也带余量，大多数副本都在平常水平附近，几乎每拍都会减弱一大片，学到的会被冲掉（"听 A 想到 B"测不出来）。步长 0.3：步长越小，长时间学得越准（打砖块 0.03 时 92%–94%，0.3 时约 91%），但 20 次"A B"之后，B 在 13 个想法名额里只占 0–1 个；0.3 时占 4–7 个。前额叶自己也能听几遍就记住（设计者 11-09；11-10 实测：一句话在工作记忆窗口里说完时，"T ? YES" 听 20 段、"NOT T ? NO" 这类 4 句听 1–2 遍就学会；步长加大到 3–10 反而不稳）；海马体也负责快速记忆。
- 想法名额只给此刻外面没亮的副本：已经从外面亮着的副本再被想到不改变任何东西，不该占名额。
- 想法不是越多越好：学过的大脑，兴奋度为平时输入量的 10% 时记得最长，100% 时想法互相干扰，反而记不住（11-10 实测）。

## 七、不要用

- 反向传播、全局梯度；
- 神经元给自己加分保持亮（自我保持项）；
- 用不应期推动想法；
- "后亮的抑制先亮的"；
- 时间环、时间细胞；
- 一个字一个神经元、编号、列表、记录表之类的程序捷径；
- PMI 闸门、枢纽抑制、除法增益、出生偏置之类的补丁；
- 单独的误差修正读出层、单独的基底节或价值模块（第四节里第一层副本对最后一层连接的自我检查不算，它就在前额叶自己的连接上）；
- 照着测试世界写的反射和开关；
- 用回应多少定奖励。

## 怎么用

- 只读本文就能搭模型。
- 测试看功能：有规律地听到声音，能不能作出正确回应。
