# concept-brain

模仿真实大脑、**边运行边学**的 AI 架构（研究原型）。不用梯度、不用反向传播。

- 设计与实验结果：[DESIGN.md](DESIGN.md)
- 代码全部重写；以前几个库只用来理解架构意图。

## 目前做到

| 部件 | 状态 | 一句话结果 |
|---|---|---|
| 序列皮层（意外时长组合单元） | 已实现 | 组合任务 7% → 100%；换规则后 400~500 个样本重新学会 |
| 概念层快速绑定 | 实验验证 | 一次学会、想起 100%、老知识 10/10 不伤；字级表示做不到 |
| 海马体（快涨快降，只管短期记忆） | 已实现 | 新记忆马上想起、按降权速度淡去，老知识始终 10/10；皮层直接快学 3000 句后老知识掉到 4.2/10 |
| 整体降权（全脑共用清理） | 已实现 | 海马体、序列皮层都只登记可塑边，由它统一降权、删除 |
| 前额叶工作记忆 + 自/他标记 | 待做 | |
| 说话门 / 运动 | 待做 | |

数字来自合成数据、3 个种子，用来确认机制成立，不是性能承诺。

## 运行

```bash
pip install numpy
python experiments/exp_composition.py   # 实验 A：组合 + 换规则（几秒）
python experiments/exp_binding.py       # 实验 B：绑定 2×2（约 20 秒）
python experiments/exp_hippocampus.py   # 实验 C：海马体短期记忆（约 1 分钟）
```

结果写到 `results/`。
