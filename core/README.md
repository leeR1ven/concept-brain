# core：照 docs/ARCHITECTURE.md 搭的唯一一套模型

| 文件 | 内容 |
|---|---|
| `net.py` | 神经元、所有区共用的局部网络生成方式、学到的连接、唯一的学习规则和降权 |
| `brain.py` | 听觉区、触觉区、链式神经元、前额叶、海马体、运动区、奖励 |
| `gen0.py` | 第一代手动连接：前额叶里"音 ↔ 肌肉"、运动区落定 |
| `config.py` | 全部参数 |
| `life.py` | 出生（孩子不出声、不学习）、一生的运行、探测 |
| `check.py` | 新生儿快速检查（几分钟） |
| `world/` | 对话世界、耳朵、皮肤（世界，不是大脑） |

运行：`python -m core.check 0`（需要 torch、numpy）。
