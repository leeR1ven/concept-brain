# 2026-11-10 大数据：前额叶为什么学不会"下一个音节"

## 世界和测法

- LCCC 中文闲聊对话，转成带声调的音节，4 个合成人声，两人轮流说。
- `syl_ticks=1`：每拍一个整音节，耳蜗分三段（声母、韵母、结尾）同时给出。
- **下一个音节测试**（`CorpusLife.next_ranks`）：
  - 在留出的对话里，每个音节处取前额叶对下一拍第一层副本的推动。
  - 候选是训练集最常见的 300 个音节，按推动和各音节编码的余弦排名；看真实下一个音节排第几（瞎猜 150.5）。
  - 编码按语境取数：冻结状态下听训练对话，某音节被听到时下一拍亮起的副本取平均。
  - 读两种副本：
    - 声音副本：听觉区第一层的副本，稠密，很多音节共用；
    - 概念副本：稀疏。
  - 对照：
    - 按频率计数、按上一个音节计数；
    - 同样的计数折算成编码的混合（"as copies"），表示这种读法用完美计数能做到多好。
- **"听 A 想到 B"测试**（`CorpusLife.pair_test`）：
  - 挑后面几乎固定跟着某个音节的 A。
  - 每种嗓音单独说一遍 A，看之后几拍里，前额叶在想法中点亮的 B 的概念副本占比，和其他音节对比。

## 结果

| 做法 | 结果 |
|---|---|
| 无概念区（big1，听 1.2 万段） | 瞎猜水平（原读法 149）。按上一个音节计数此时 65 |
| 理想赫布权重（协方差，全部互连），从任何一层出发 | 仍是瞎猜。问题在编码，不在"只连附近" |
| 概念区原学法（同时亮就加强） | 两个音节编码的余弦从 0.05 升到 0.6，联想更差（110–141） |
| 概念区加"每单元学习总量上限"（竞争学习），各种强度 | 都比不学习差；越强越合并（余弦 0.71–0.90） |
| **概念区不学习**（出生随机连线、每拍只亮最强 1%），只读听觉第一层，8000 单元 | 认音节第一名 46%；离线在其上简单计数，听 600 段后预测第一名 15% = 按上一个音节计数 |
| 理想编码（每个音节一组随机专属单元）+ 同样的计数 | 排名 48、第一名 35% |
| 每音节保持 2 拍（big3/big4） | 一半训练对是"音节还在继续"，联想被淹没 |
| 概念副本与它读的特征同一拍进前额叶（big5） | 概念空间到频率水平（第一名约 4.5%），没有二元组信息 |

学习规则试验台（`rule_probe.py`）：
- 录一次新生脑听 1000 段对话时第一层的外部副本序列，然后只重放"第一层 → 下一拍第一层"这张表的学习。
- 结果为概念空间：

| 规则 | 平均排名 | 第一名 |
|---|---|---|
| 按频率计数（对照） | 92.0 | 4.8% |
| 按上一个音节计数（目标） | 80.8 | 15.7% |
| 现在的检查规则，所有副本参与 | 87.8 | 5.6% |
| 改动按副本稀有程度分配 / 按连接强度分配 / 分级（Rescorla-Wagner） | 87–89 | 6–7% |
| 只让亮率低于 2% / 5% / 10% 的副本参与 | 87.1–87.8 | 5.4–6.2% |
| 只让概念副本参与 | 81.9 | 10.6%（作废，见下） |
| 只让概念副本参与 + 分级，重放 3 遍 | 83.1 | 11.4%（作废） |

- **更正（同日晚）**：这个排名函数没有处理并列，推动为 0 的候选被排在前面，所以"只让概念副本参与"的 10.6% 和 s=2 的对比都是并列造成的假象。之后一律用 `fable-lab/reader.py` 的解码器读法（并列取平均名次）。
- 稠密的声音副本参与预测，就会把概念副本的专属信息淹没（结论本身由下面的解码器结果另行支持）。
- 筛选的关键是"专一不专一"，不是"亮得多不多"：亮得少的声音副本仍是很多音节共用的局部特征。
- 架构里结构可塑性的判据"能不能区分事物"说的就是这个。

## 下午到夜里：拦路虎是编码一致性，第二种感官解决了概念区

### 读法和规则（解码器读法，`fable-lab`）
- 计数型的表听得再多也不变好（500 → 4000 段都在 0.052–0.056）；纠错型（分级：改动 = 步长 ×（来了 − 推动））随数据变好。
- 只许权重 ≥ 0 时"听 A → 首选 B"只有 0–0.17；用抑制伙伴单元（抑制连线 ≥ 0、同一条分级检查学、突触不变号）达到 0.28–0.45，与自由符号相同。设计者批准（"可以，你们测试决定"）。
- 理想编码（每个音节固定一组）+ 分级表：A → B = 1.00；每个"音节 × 嗓音"一组：0.92–0.97。所以不需要跨嗓音不变，只要同一嗓音每次编码相同。

### 编码一致性
- 同一音节同一嗓音两次听到的相似度：耳朵 0.74，听觉第一层 0.48，概念区（1%）0.17。去掉每轮的音高、音量偏移后为 1.00。
- 原因：网络固定，差别来自声音本身的小偏移（音高、音量、耳朵噪声三者相近），被每一级"只留最强的少数"放大。听觉亮率 ×4 后第一层 0.83、概念区 0.45。
- 设计者（11-10）：高层的"相似变相同"在本模型里是概念区的事；概念区和其他区是同一种网络，通过链式神经元接收各区信号；"概念就是总是激活的神经元，特征是偶尔激活的"。原来的概念区（1% 稀疏、直接读听觉第一层）是我的设计，被判为不对。

### 概念区怎样学会"相似 → 相同"（试验台 `stay_bench`，探针时回程关）
| 老师（和声音同时点亮一组概念单元） | 结果 |
|---|---|
| 概念区更稠密（不学习）：1 / 5 / 20 / 50% 亮 | A → B 0.42 / 0.51 / 0.59 / 0.34；20% 最好但到 0.65 封顶 |
| 竞争学习六种、内部连线、"局部常亮"中间层 | 都不超过不学习的基线 |
| 前额叶对下一拍的预期当老师（闭环） | 把音合并：它预期的多是什么音都常亮的单元 |
| 海马式回忆（最像的 10 个）当老师 | 精度 0.46 → 0.62，但识别反而下降：错误都是"听起来像的音"，系统性地合并该分开的 |
| 神谕老师（知道是哪个音节），规则 b，100% 在场 | 识别 0.82 → 0.93，A → B 0.47 → 0.78（3000 段，仍在升） |
| 同上，只在 50% / 20% / 10% 的音节在场 | 0.90 / 0.87 / 0.85，A → B 0.67 / 0.54 / 0.52；都无漂移，只是变慢 |
| 50% 在场且 20% 错 | 0.89，A → B 0.58 |
- 规则 b：同一条分级检查，每个单元先减去自己平时收到的学习推动（架构 二.4）；不看是什么点亮了单元（无"门"）。带"门"的版本在老师缺席时把学到的推回 0，被淘汰。
- 结论：只靠声音找不到准确的老师；需要一个每次都一样、和声音同时出现的东西，即第二种感官（如听到字时看到字）。

### 全脑第八、九次（`train_corpus`，听 6000 段）
- 第八次（前额叶只经概念区、分级表 + 抑制伙伴、回声门、停止副本不发）：念头 100% 落在概念副本上；听 2 万段后"B 被想得最多"0.1–0.2，不再随听得多而升。
- 第九次（概念区规则 b + "看到字"：每个音节一个固定图案，部分音节出现；测试只用声音）：
  - 前额叶想法的回程当老师：概念上限 0.78 → 0.30–0.44，改为回程不参加概念区的检查（`concept_ret_teach=False`，默认）。
  - "看到"按"比什么都不看时高"选单元，会造成通用单元（两个字的单元集合重叠 13%，机会 1%）；改为按各单元自己看到东西时的平时水平（架构 二.4），重叠 1.15%。
  - 修正后，只用声音时的概念上限：每次看到 0.82 → 0.91，一半 0.84 → 0.88，20% 0.81 → 0.85，不看（旧版）0.78 不变。概念区这边成功。
  - 前额叶还没受益：预测下一个音节仍是旧版水平，平均名次反而变差。推测是"看到"点亮的单元也送进了前额叶，学的编码和测试时（只有声音）不一样；正在测只用来教、不送进前额叶（`sight_to_code=False`）。

## 和架构原文的偏差（每项写恢复条件）

| 偏差 | 原因 | 恢复条件 |
|---|---|---|
| `syl_ticks=1`，每拍一个整音节 | 训练快 3 倍 | 学习规则能处理多拍音节（时序赫布按"刚灭→刚亮"学）后，回到多拍 |
| `concept_sync`：概念副本与特征同一拍进前额叶 | 每拍一个音节时，晚一拍 = 晚一个音节 | 同上 |
| `concept_from=(0,)`：概念区只读听觉第一层 | 更深的固定层滞后，且丢失身份（46% 对 24%） | 深层不再丢身份，或多拍音节下滞后不再错开音节 |
| 概念区规则 b + 第二种感官（`concept_rule='b'`、`sight_bits`） | 只靠声音的老师都会合并音节 | "看到"目前是直接接到概念单元的输入位，每个音节一个随机图案，没有视觉区和链式神经元；做出真正的视觉区后替换 |
| 回程不当概念区的老师（`concept_ret_teach=False`） | 想法常错，当老师会毁掉编码 | 想法足够准时再测 |
| `predict_from` 加了第一层的表 | 每拍一个音节时，最后一层晚 3 个音节 | 多拍音节 |
| `predict_from_concept`：第一层的表只从概念副本出发 | 稠密副本淹没专属信息 | 若"前额叶只经概念区接收感觉"成为架构（设计者 11-10 的设想），它就不再是开关 |
