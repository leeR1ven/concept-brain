# 2026-11-04 激活的神经元有没有规律（`core/pattern.py`）

不预设模型该想什么（它可能顺着话往下想，而不是复述），只比较激活的神经元本身。数字是两次激活的重合度（Jaccard），格式为"同一句 / 不同句"。

## 测法

- 听一句话的前三个字，看之后 9 拍里各层亮了哪些神经元。
- **同一时刻放两次**：从同一个大脑状态出发，放两次，耳朵噪声不同。
- **隔一段时间**：先放一次，过 20 段对话后再放一次。
  - 冻结模式下，这 20 段里权重和门槛都不变，唯一的差别是听之前大脑的状态。

## 同一时刻：前额叶有规律

life2（大号，6.9 万段）：

| | 同一句放两次 | 换声音 | 不同句 |
|---|---|---|---|
| 想法 | 0.61–0.72 | 0.49–0.51 | 0.15 |
| 最后一层 | 0.78–0.86 | 0.67–0.70 | 0.25–0.28 |
| 海马体自己的神经元 | 0.08–0.09 | 0.04 | 0.016 |

- 训练让换声音的一致性明显变好（想法从新生的 0.17–0.23 升到 0.49–0.51）。
- 海马体自己的神经元很不稳定。把它学到的连接清空后，"同一句放两次"反而从 0.09 升到 0.21。

## 隔一段时间：最后一层完全不同

冻结模式，听之前安静 4 拍：

| 层 | 同一句 / 不同句 |
|---|---|
| 听觉输入 | 0.50 / 0.28（稳定） |
| 前额叶第 2、3 层 | 0.65 / 0.52、0.81 / 0.78（稳定） |
| 最后一层（听时） | **0.00 / 0.00** |
| 想法 | **0.00 / 0.00** |

输入和中间层都稳定，信息丢在最后一层。之前的解码测试都是从同一状态出发，所以看不出这个问题。

## 找原因

| 改动（只在测试时） | 最后一层（听时） |
|---|---|
| 学连接设上限（6 / 2，重新练 3 千段） | 仍不稳定，学到的东西变少 |
| 内部推动的起伏不超过输入（重新练） | 仍不稳定，学到的东西变少 |
| 回送强度 0.95 / 0.8 / 0.6 / 0 | 仍不稳定 |
| 清空最后一层 / 前额叶 / 海马体 / 运动区 | 仍不稳定 |
| 兴奋度 context 0.05 / 0 | 仍不稳定 |
| 清空听觉区（前额叶的输入一下变成几乎为零） | 0.66 / 0.18（稳定） |
| **最后一层内部连接设为 0** | **0.53 / 0.44（稳定）** |

听之前安静多久：

| 安静 | 4 拍 | 8 拍 | 15 拍 | 30 拍 | 100 拍 |
|---|---|---|---|---|---|
| 最后一层（听时） | 0.00 / 0.00 | 0.15 / 0.14 | 0.69 / 0.19 | 0.58 / 0.19 | 0.67 / 0.22 |

结论：
- 最后一层的内部连接会把刚听到的内容"抓住"约 10 拍。
- 对话中两轮之间只隔 4–10 拍，所以每句话都被上一句盖住。
- 新生大脑在安静 4 拍时还有 0.28 / 0.15 的稳定性，练过后为 0。也就是说，内部连接越练越强，旧内容越难让位。
- 模型学到的东西本身有规律：安静 15 拍以后，同一句话的反应稳定，而且和不同句子分得清。

## 概念区降权

概念区原来用前额叶的降权速度（每 200 拍 0.99995），太慢。

| 概念区降权 | 最后一层"听什么都亮" | 想法解码 |
|---|---|---|
| 0.99995 | 63–88% | 0.11 |
| 0.9995 | 21% | 0.23 |
| 0.995 | 15% | 0.16 |
| 不加概念区 | 0% | 0.28 |

## 更正（同日）

- 上面"最后一层不稳定 = 问题"的判断不成立。外界对想法影响多大是参数，不分对错；不应自定"外部要压住内部"的标准。
- 曾把不同层的重合度直接比较，得出"越往后越差"，是错的：各层亮的比例不同，碰巧重合的程度也不同。

## 直接测试：听"A B"20 遍，再只听 A，B 的副本有没有被想到（`core/ab.py`）

| | B 的副本推动超过门槛 | B 实际被点亮 / 当拍想法总数 |
|---|---|---|
| 新生（大号） | 521 | 28 / 36 |
| 新生，想法名额按平时输入量算 | 691 | 31 / 57（约一半是 B） |
| life2（7.9 万段） | ~190 | 0 / 12（推动几千的旧东西占满名额） |

- 赫布连接确实记住了"A 后面是 B"。
- 原规则下想法名额 = 这一拍外部输入量的 10%，A 说完就安静，名额几乎为零，B 点不亮。改为按平时输入量算后能想起来，已采用。
- 小号对照训练（`core/abpairs` 之前的单对测试）：名额改后练到 3 千段，不额外训练就能从语料里学会这一对（想法 15/23 是 B）；但 1 万、2 万段又降低，正在查降权速度。
