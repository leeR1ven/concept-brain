# 2026-11-03 体检和参数搜索

## 体检（`core/exam.py`）

每个存档跑同一套测量，并和新生大脑对比。看的是趋势，不看单个数字。

- **A 解码：** 用 3 种成人声音认识 60 句话，再用第 4 种声音考，看能认对多少。随便猜是 1/60。
  - 分别看：输入、前额叶最后一层（听时和听后）、想法、海马体回忆。
  - 模型听懂了也可能不去想，所以要直接看大脑状态里有没有句子信息。
- **B 思考范围：** 听完一句话后，同一句话换人说和不同的话相比，想法重合多少。
- **C 一次记忆：** 没听过的话只听一次，再用前三个字提示，看能不能想起第四个字。
  - 分"马上"和"隔 20 段对话"两种，同声音和换声音两种。
- **D 健康：** 最后一层有多少"听什么都亮"，学到的权重有多大。

## 句子信息在前额叶中间层丢了

先看新生大脑。下表都是小号大脑（s=1），数字是换声音考时 60 句里认对的比例。

| 前额叶中间层亮的比例 | 输入 | 最后一层（听时） | 最后一层（听后） |
|---|---|---|---|
| 2.6%（原来，等于输入层密度） | 0.40 | 0.06 | 0.06 |
| 10% | 0.44 | 0.21 | 0.18 |
| 30% | 0.44 | 0.41 | 0.33 |
| 50% | 0.43 | 0.42 | 0.37 |

每个神经元的输入数 K 从 6 加到 12、24、48，最后一层只到 0.10 左右。

原因是：中间层亮得太少，每个神经元太挑剔，同一句话换个声音就被拆成完全不同的反应。

## 学习曲线

16 个孩子一起练，测前额叶的想法。

| 中间层 | 练了多少 | 想法解码 | 同一句 / 不同句（想法重合） |
|---|---|---|---|
| 2.6% | 1 千段 | 0.05 | 0.049 / 0.043 |
| 2.6% | 1 万段 | 0.07 | 0.103 / 0.087 |
| 30% | 1 千段 | 0.17 | 0.218 / 0.072 |
| 30% | 3 千段 | 0.18 | 0.201 / 0.057 |
| 30% | 1 万段 | 0.18 | 0.314 / 0.096 |
| 15% | 1 万段 | 0.20 | 0.174 / 0.030 |
| 50% | 3 千段 | 0.15 | 0.157 / 0.049 |

选定 30%：
- 规律最早出现，同一句约是不同句的 3 倍；
- 不同的话之间仍保留一些重合，不会降到 0。

## 其他没起作用的改动（练 3 千段）

以下改动都没有明显改善，原因见下：

| 改动 | 结果 |
|---|---|
| 学习快 5 倍 | 没有明显改善 |
| 前额叶降权快 10 倍 | 没有明显改善 |
| 平时水平跟得快 5 倍 | 没有明显改善 |
| 想法数量多 3 倍 | 失控：最后一层 100% 卡住 |
| 最后一层内部推动小 10 倍 | 想法每次都不一样，重合为 0 |
| 改特征神经元上限（0.05 到 0.6） | 差别在波动范围内 |

## 还没解决：一次记忆

听一次后马上用前三个字提示，海马体也几乎想不起第四个字（排名接近随便猜）。

查到的原因：
- 耳朵每次有约 15% 的随机起伏；
- 同一句话放两次，送进海马体的副本只有约 52% 一样；
- 海马体自己的编码只有约 17% 一样（每拍只有 50 个亮，太挑剔）。

几种改法的结果：
- 每拍亮的数量加到 800，编码一致程度升到 28%，但回忆还没变好；
- 关掉回程或噪声，副本一致程度几乎不变。
